## 库名迁移

脚本：`backend/scripts/rename_production_database.py`。默认只检查，显式 `--apply` 才写入。

执行时暂停后端写入，将完整 SQL 和环境文件备份到服务器 `/opt/bacoach/backups/database-rename-<UTC时间>/`（仅所有者可读）；复制全部表后对每张表做行数和内容摘要校验，再更换环境文件中的数据库名并健康检查。

旧库不会被删除；目标已存在时拒绝覆盖。切换前失败会恢复后端，切换后健康检查失败会恢复原环境文件。新库开始接收真实写入后，回退不能仅切回旧库，需先处理切换后新增数据。

**库名迁移不等于 V2 结构升级完成。** V2 的表结构、抽取、目标与周期生命周期、网页交互、数据校验及 DMS 元数据核验须另行完成验证后才能标记上线完成。
