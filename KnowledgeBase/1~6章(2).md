# 艾丽西亚-工作
 
自从丢了程序员的工作之后，每天早上艾丽西亚（Alicia）都害怕起床。她知道被解雇是很常见的事，但她还是责怪自己多次和老板叫板，在会议上说出格的话。她唯一的收入就是失业补贴，一开始她很难维持生计。拿着这么一点钱很难生活下去，她只好卖掉公寓，租了一套小点的单元房。艾丽西亚相信，一旦找到合适的工作她就会有更多精力，生活也更有希望。但是后来她并没有找到工作。她花了8个月的时间找工作，最后只在一家小公司找到更新网站的临时工作。收入不高，并且无聊透顶。上司对她的工作或者计划一点都不感兴趣，即使迟到2个小时也没有关系，所以她总是赖床。
 
工作的折磨不是唯一的问题。她还有着一大堆担忧和焦虑，在被解雇前她就有了这些感觉。事实上，她偶尔会睡不着觉，然后赖床缺勤。她更多时候是在晚上焦虑，她主要担心自己感觉很不好，担心自己不能平衡得失，不能在生活上获得成功。她最频繁的担心是害怕自己的情绪会影响到和男朋友的关系。
 
 # 艾丽西亚-朋友
 
随后，艾丽西亚经历了更多的生活变化，她开始远离人群，不再参加那些从前带给她快乐和刺激的各种活动，她的情绪也变得更糟。在搬家之后，艾丽西亚不再邀请朋友到家。她觉得这么小的房子，这么破旧的设施只会让自己尴尬。她所在的社区很安全，但是位置不好，离机场很近，以前她和朋友还嘲笑过这个地方。所以，她既不邀请朋友到家，也不去拜访她们，因为她害怕谈到工作的问题。而且她嫉妒朋友们的富裕生活，这让她感觉不好。所以她干脆一躲了之。但是很不幸的是，有三四次她没有参加活动后，有几个朋友再也不联系她了。她失去了那几个朋友，但是无法鼓起勇气打个电话解释一下。
 
 # 艾丽西亚-家人
 
艾丽西亚觉得被朋友遗弃很难受，因为她的家庭关系长期不好，最后导致妈妈在她过完17岁生日后2个月就赶她出门了。她跑去和朋友一起住，并且有3年时间没有和妈妈说过话。她说那是她生命中一段令人非常伤感和烦心的时光。
 
# 对当前状态的解释

贝丝解释说，当感觉生活没有回报时，很自然会让人感到悲伤、疲倦和无望。这些感觉往往在焦虑和担忧一段时间之后出现，特别是失去一份好工作后肯定会出现。当一个人有这么多情绪时，很容易理解她为什么待在床上不愿意起来。艾丽西亚对这种说法很好奇。她自己常常认为(或者家人告诉她)自己的行为不可理喻。如果她的生活陷入困境，为什么不更努力一些，而是整整一早上躺在床上？找份新工作也不那么难呀，她无数次对自己说。
 
 # 行为激活疗法的目标
 
贝丝建议以行为激活疗法作为治疗计划。"目标是让你重新参与各种给你带来快乐和满足的活动，即使你的生活处境已经发生了变化，"贝丝解释道，"这会帮助你改善那些困扰你和让你失眠的处境。"最后贝丝问她愿不愿意尝试6个疗程的治疗，来看看这种方法是否有帮助，然后再决定进行更长时间的治疗，艾丽西亚说，她已经什么都没有了，不妨放手一搏。
  
# 什么是抑郁症的行为激活疗法？

行为激活疗法是针对抑郁症的一种短期的结构化治疗方法，旨在通过增加生活中的回报感来激活来访者。行为激活疗法的所有技术都服务于一个基本目标,那就是增加行为激活,让来访者参与到生活当中。针对这个目标，行为激活疗法还关注那些妨碍行为激活的因素，比如逃避和回避行为。行为激活疗法的假设是,抑郁易感个体面临的生活问题使他们无法从环境中获得回报感，从而导致我们称之为抑郁的一系列症状和行为。为了缓解抑郁，行为激活疗法假设我们必须协助来访者采取行动,从而带来愉悦感或实际效果，或获得更大回报从而改善生活处境。行为激活的各个疗程都是行动取向的,关注问题解决。事实上，大部分治疗工作在治疗室外完成。每一周，治疗师和来访者一起工作,布置下一次治疗前需要完成的作业,克服行为激活过程中遇到的障碍。
 
 # 行为激活疗法的高度个人化
 
在这种结构化的治疗框架内，行为激活疗法其实是高度个人化的。在治疗早期，来访者和治疗师共同识别抑郁症相关的行为模式，这些模式因人而异。你将会通过本书学会识别这些模式，并制订相应的治疗计划。例如，一些来访者总是被动不作为，睡觉太多，看电视或者酗酒，通过这样做来缓解负面情绪。另外一些来访者则非常活跃，毫不困难地完成日常工作，然而他们会沉浸在漫无止境的反刍当中，并且体验不到参加活动的乐趣。基于对行为模式的分析，我们可以确立一系列的治疗目标，随后的治疗便可以针对这些领域不断改变来访者的行为。
 
因为行为激活疗法的目标是为来访者量身打造的，所以涉及的治疗目标较广泛。例如，行为激活疗法帮一名女性来访者学会了容忍负面情绪的存在,特别是结束一段重要的友谊之后的沉痛感受。她的行为激活就是学会处理并走出悲伤情绪，重建旧的人际关系并且发展新的人际关系。还有一位来访者通过更新简历来找工作,给前同事打电话询问有无职位,进行面试的练习。在治疗期间，她还开始了健身计划,并且每日定时起床。
 
# 来访者的担心与咨询师的回应
 
来访者第一次治疗时，通常不能确定从咨询中能得到什么。事实上，很少有人在治疗一开始就想要让自己更有活力。抑郁症很容易让人退缩，活动减少。许多抑郁症来访者在治疗前都认为要变得有活力并改变自己的生活，先要等情绪好转才行。但是假如来访者在采取行动之前就想要有动力，治疗又如何发挥作用呢？就像艾丽西亚的治疗师所说的，在治疗一开始正面回应来访者的这类问题和担忧是非常重要的。
 
行为激活疗法是结构化的治疗方法，在早期解释治疗的核心要素非常重要。这些核心要素包括抑郁的行为激活和改变模型。在行为治疗之后，治疗师和来访者要能够预期哪些行为诱因可能引起或增加抑郁症状，并且做个备选的行为计划，帮助来访者应对这些情境。
 
行为激活疗法的标志是包含一系列结构化和风格化的核心策略。例如艾丽西亚的第二个疗程，贝丝表达了对艾丽西亚生活经历的真诚关注和兴趣。当艾丽西亚对于是否接受治疗犹豫不决时，贝丝用实事求是和不做评价的态度来回应。她鼓励艾丽西亚表达她的问题和担忧，并邀请艾丽西亚积极参与到治疗中来。
 
# 行为激活的结构: 由外而内

关注行为的"激活"从根本上决定了行为激活疗法的结构。行为激活疗法的原则一和原则二就反映了这一思想。原则一概述了行为改变的模型，"改变人们感受的关键点是帮助他们改变自己的行为。"这个原则的前提是，假如来访者被动等待有活力的时候再去行动，那么他们就会在原地踏步。由于这种困境,我们会要求来访者由外而内地改变，而不是由内而外地改变。也就是说，行为激活疗法结构的关注点不是考虑来访者内在感受如何，并期望以此提升动力，而是反过来直接付诸行动。作为治疗师，我们就要当教练，来帮助来访者由外而内地改变。我们通过分解行为，来增加来访者改变的可能性，哪怕他们的行动力极低。另外，为了增加来访者遵循目标行动的可能性,我们会帮助来访者建立日常生活的规律。

 # 行为激活的结构：抑郁模型
行为激活的第二个原则概括了抑郁模型，并关注行为激活疗法的"激活"成分：生活中的改变可以导致抑郁，短期的应对策略使人们陷入持续的困境当中。早期的抑郁行为模型强调说，当人们的生活正强化少而惩罚多时抑郁更容易发生。为什么呢？在这种情景下，人们可能学习到行动不会带来好的结果，或者是学会如何逃离、回避环境中的惩罚，从而学会了从生活中退缩，不再参与到生活当中。这会让一个人陷入抑郁。一个人做得越少，就越不想做事；然后做得更少，在他的生活中问题就会堆得越来越多。当正强化减少，惩罚增加时,抑郁的恶性循环就开始了。当一个人试图排除这些困扰却无能为力时，自我意识便会增加。自我意识增加和恶劣心境会导致与抑郁相关的一系列认知、行为和情绪的改变，从而使一个人将来缺乏能力去应对那些诱发抑郁的事件。
 
个体试图减少情绪困扰是可以理解的，但是他们实际所做的，比如对于压力的负面思维，逃离或者是回避讨厌的经历，试图回避情感上的痛苦等，都会减少环境中的潜在强化物。这种退缩行为会让抑郁个体陷入一种糟糕的情绪模式。最终情绪系统关闭，抑郁个体感到更加糟糕，日益消沉，对改变不再抱有希望。 
 
 # 如何建立个案概念化
我们首先要问"来访者生活中发生了什么（可能）引发了抑郁?"。原则三指出：明确对特定来访者说，什么能够对抗抑郁，可以看他重要行为发生前后的事情。这个原则对于理解来访者过去被强化了的、未被强化的或者被惩罚了的行为非常关键。

通常，来访者会报告关系或者事业破裂，经济负担或是损失，或者孩子出生这样的生活变化,甚至还有生活琐事。有时候来访者会强调生物因素，那么我们就会解释在理解生活事件时,需要同时考虑生物因素和环境因素。尽管这不是我们通常所讲的"生活事件"，但是行为激活疗法所指的生活事件可以拓展到生活内外部经验。

我们会考察这些事件的影响，特别是获得奖赏的途径是否有限，或者压力日渐增长等。然后我们会转向这种生活处境如何影响个体的体验。通常来访者会说："感觉很糟糕。我觉得悲伤、孤独、沮丧和没有希望。"在向来访者解释这个核心成分时,交流的要点是讲明，抑郁不是一个人的错,在那种情形下感到抑郁是可以理解的。
 
来访者应对抑郁情绪的方法本身导致负性情绪加剧，渐渐地带来其他一些因素使抑郁更经常发生。
 
# 抑郁相关的问题
- 抑郁症不是由于脑子里面的化学物质不平衡引起的吗？
 
答：我们知道我们的生理状态和抑郁是相关的，我们还知道改变行为可以影响身体的化学状态。抑郁症是多种因素导致的复杂情形。幸运的是，抑郁症是可以治愈的，许多治疗方法都能提供帮助。

- 如果我抑郁的时候表现得不抑郁，不是看起来很假吗？
 
答：人们常问这个问题。这听起来可能会让人觉得尴尬，但是当你抑郁的时候，在行动上参与更多并不是在假装或者不诚实。就像不抑郁的人那样去做事情,你会感到好受，并在生活中感受到支持和幸福。
 
- 假如我已经够忙了，而且就是因为太忙才抑郁，我怎么可能再增加活动呢？
 
答:事实上，可能你要做的事情太多了。我们要看下所有这些活动对你有什么影响，我想帮你，使你做更多事情，全力投入并且不感到筋疲力尽。

# 行为激活是否太简单
- 这种方法会不会太简单？
 
答：这种疗法的思想简单明了，但是付诸实践则很难。这就是为什么在改变你的行为的同时，需要我来充当你的教练。当我们一起努力的时候，我会帮助你循序渐进，一步步变得有活力，能够不断解决生活中的问题，并体验到更好的情绪。这种方法很强大,但是我们也常常对来访者讲，如果这种方法真的做起来那么简单，你早就已经这样做了。
 
 # 行为激活的效果
- 想要有活力似乎是不可能的，我抑郁的时候都起不了床。这个方法真的会对我有帮助吗？
 
答：当你感到抑郁的时候，你会觉得这一切都不可能，你会质疑是否能够有所改变。人们会发现一开始看起来不可能的事情，当他们更有活力、更愿意参与的时候，就渐渐变得容易起来。这种方法是非常实用的，我的工作就是帮助你理清楚如何着手，如何找到目标和方法开始着手当前能做到的事情。对某些人来说，告诉他们这种方法对许多得抑郁症的人有效，同样会有所帮助。尽管如此，我不能保证治疗成功，因为这是不诚实的。我承诺将和你一起努力，从现在开始，从这里开始。我认为当我们获得进展后，这些做法对你来说会更可行。如果你愿意,你可以从一些小的步骤开始，观察效果，然后再进一步往前推进。
 
- 假如其他疗法都试过了不管用，行为激活疗法可能有效吗？
 
答:行为激活肯定不是万能药。但是我从研究当中知道，这种方法可以帮助抑郁的人。用这个疗法做个试验怎么样？我们一起努力一段时间，看看这个方法对你是否有效。我不能保证成功，那我们约定个时间讨论下治疗进展，比如四到五个疗程之后可以吗？我们可以那时候再探讨哪些方面起作用了，哪些方面没起作用。你觉得怎么样？

 # 来访者的质疑
一种反对的声音是这个模型听起来过于简单。我们通常会承认这个模型比较简单和直接，但是告诉来访者模型的建立考虑到了治疗抑郁症的难度。我们强调说,模型有时会让来访者感觉，要强迫自己做一些简直不可能完成的任务来增加活力。对于来访者的这种担忧,我们应该强调改变行为是不容易的,治疗师关键是要充当导师或教练，就像前面提到的一样。
 
假如咨询熟练的话，治疗师可以通过向来访者解释行为激活模型,来建立咨询关系。在最初的访谈中可以用模型来解释一些生活细节，表明治疗师开始理解来访者的处境。但是个案概念化总是以假设的形式出现的，治疗师想当然地认为他知道什么是导致或者维持了某人的抑郁症状，而这是不明智的。因此我们必须做出假设,并验证假设，然后提出一个模型,来运用行为激活的多个策略。功能分析，也就是考察行为发生的前因后果是贯穿治疗始终的。具体来说，为了推测是哪些行为让抑郁维持下来的，治疗师会去分析行为的功能,及该行为对来访者的影响。例如,来访者穿旧的运动裤去商店可能是为了舒适，可以快去快回，也可能是为了避免花时间和精力去搭配合身的衣服。
 
# 保持行为激活
保持行为激活这个主题,不是说治疗师不关心来访者的内心生活或者过去的问题。行为激活治疗师和来访者探讨过去，往往是在个案概念化阶段展开的。过去的信息可以帮助治疗师对来访者生活中强化/惩罚的依随关系形成假设,从而指导来访者此时此地要做什么,怎样才能让他们重新参与到生活中。例如很久以前妈妈将她赶出家门时艾丽西亚非常受伤。尽管后来她又和妈妈和好了，但是仍然和两个妹妹感觉疏远。在治疗中，她提到妈妈伤了她的心，内心非常痛苦。和贝丝谈论这些对她来说很难。当谈话引出悲伤、愤怒、内疚或者羞愧情绪时,贝丝引导艾丽西亚谈怎样处理这些情绪而不是逃避情绪，如何迈向生活中重要的目标。在治疗中讨论并体会这些复杂的情绪，让她有机会考虑和妹妹们修好，而此前她尽管想这样却不敢去做。
 
 # 艾丽西亚-家庭关系
艾丽西亚：我总是想到去年和妈妈关系最差的时候。她当着弟弟妹妹的面说了那么多难听的话。有时候我想这些话说对了，我觉得很不好。我想弟弟妹妹们感觉也一定不好。我没有和他们提起过，我小的时候妈妈多难。她酗酒，我则非常叛逆。当他们长大一些能够知道一些事情后，妈妈就不再酗酒了，但是和我的关系仍然很糟糕，我想弟弟妹妹们都在埋怨我。
 
贝丝：听起来你很想和弟弟妹妹联系，但是你一想到要去联系他们就感觉很糟糕。你上个星期很多时候都在想这个吗？
 
艾丽西亚：星期天是这样。我想我应该打电话给我妹妹，简单打个招呼。但是以前星期天就像地狱一样，妈妈喝醉了酒，然后我们假装高兴。我总是气得发疯，骂这糟糕的生活。妹妹还记得我说过的一些骂人的话，好像是我把她的星期天毁了，但是她却不记得星期天对我来说感觉有多糟。
 
贝丝：所以你星期天想到这些过去的事情，然后决定不打电话了？
 
艾丽西亚：是的。我实际上很多时候都在想过去的事。特别是我当着弟弟妹妹的面和妈妈吵架。她指责我带来了这么多问题。我不知道弟弟妹妹是否也同样责怪我。
 
 # 艾丽西亚-设定目标
贝丝：所以你不想在打电话的时候聊起那些事情。那你有没有什么特别想和妹妹说的呢？
 
艾丽西亚：我想到，我可以提议在电脑上视频通话，她就可以给我看看她的猫。我想那是只小猫。如果我的狗看见那小猫狂叫起来应该会很有趣。但是我不愿意回想,过去妈妈对她比对我好多了，妈妈一直抱怨我们过得不好是我造成的。那种想法让我感觉更加孤立无援，好像就是我傻傻地毁了全家的生活一样。
 
贝丝：艾丽西亚，我理解你，你不愿意再想到或者经历那些感受。但是从你讲到的来看，你还是想从和妹妹聊天中有所收获。其他时间可不可以打电话给她，这样就不用像星期天打电话感觉那么糟了？
 
艾丽西亚：有。
 
贝丝：那你更愿意在哪天给她打电话？
 
艾丽西亚：我想星期五晚上会好些。她结束了一周的工作，那天打电话不会像星期天感觉那么糟。
 
贝丝:这个时间打电话你感觉会好些吗？
 
艾丽西亚:我想是的。
 
贝丝:那你这周怎么计划呢？
 
# 目标 vs 过去经历
贝丝接下来和艾丽西亚着重讨论了和妹妹拉近关系能采取的具体做法。整个谈话过程中，贝丝和艾丽西亚谈到了艾丽西亚以往的一些生活；但是接下来的谈话又重新聚焦到艾丽西亚可以做哪些其他事情，来实现这个重要的生活目标上。简言之，行为激活是以目标为导向的，每个疗程治疗师和来访者共同设置议程表。行为激活疗法对于如何安排不同的疗程没有具体要求,治疗针对不同来访者也因人而异。指导原则已经告诉了治疗师如何组织治疗，治疗师可以根据来访者调整他的咨询风格,帮助来访者增加行为激活程度，从而使来访者有更多机会接触正强化物并增加抗抑郁行为。
 
## 治疗师的个人风格
行为激活疗法是行动导向疗法，治疗师组织治疗和推动行为的风格非常关键。

行为激活治疗师有效的治疗风格和立场
 
- 维持不同疗程的结构
 
- 坚持行动导向
 
- 认可来访者的经历
 
- 与来访者合作
 
- 采取非评判性立场
 
- 真诚地关怀来访者并传递温暖
 
- 在治疗中强化适应性行为的口头报告或者行为表现
 
# 认可（Validation）

认可来访者意味着理解来访者的经历。行为激活疗法的中心是熟练"读懂"来访者。行为激活治疗师可以使用复述或者反映技巧来回应来访者。准确回应来访者的细微或者非言语的沟通内容是认可的关键要素。
 
有效的认可通常意味着你对来访者感受的理解，而这是基于对他们生活史和现状的了解。在开始的访谈中，治疗师仔细倾听来访者叙说对其有影响的生活事件。然后在介绍行为激活模型时，治疗师将可能导致来访者抑郁的生活事件反馈给来访者，借此治疗师可以和来访者核实自己是否理解了来访者的经历。治疗师还可以用来访者自己的话来谈论抑郁症状。最后治疗师说明,鉴于来访者的生活史和现在的情绪，对症状的那些反应是可以理解的，但是这会加重抑郁症状，并减少来访者接触正强化物的机会,让来访者的问题更加复杂。这种针对抑郁症状出现的行为反应是一种继发性问题。大多数来访者觉得和治疗师讨论行为激活模型，可以获得认同感,可以准确反映他们的情绪体验。如果来访者不同意治疗师的看法，治疗师需要持开放态度去理解，如来访者对自身体验是如何知觉的，然后相应地去修正模型。假如没有认可,就不能抓住治疗师和来访者互动的要点,治疗师需要避免这个问题。
 
# 案例-如何认可来访者

来访者：我这星期没有时间去邮局买邮票，所以没有寄出上周治疗布置的家庭作业。
 
治疗师：你遇到了困难吗？
 
来访者：主要是我的臀部和膝盖痛，我要等好一点后才能步行6个街区去邮局。还有我的公寓得上下楼梯。我不需要购买食品，所以就没有出去。
 
治疗师：可以理解。这件事让你感到痛苦，我很抱歉。是身体原因妨碍了你完成上周我们讨论的行动计划。
 
来访者：是的。
 
治疗师：上周我们提到和孩子们保持联系对你很重要，所以才认为定期给他们寄信是个好方法。我知道身体原因让你没有完成上周的任务，所以我想问下你觉得这个计划是不是值得去坚持？
 
来访者：我觉得值得。只是我不确定能不能做到。
 
治疗师：这是个大问题。也许有其他办法让你买到邮票。稍后我们可以谈谈这个吗？
 
来访者：可以。我想可以在网上买到邮票，只是我从来没试过。
 
治疗师：你可以上网吗？
 
来访者：可以，我不经常用电脑，不过需要的话我可以上网。
 
治疗师：好的，那让我们谈谈怎么样买邮票,这样你就不用上楼下楼，生病时也不用到处走动就能够买到邮票吧。
 
 # 如何认可来访者
治疗师基于来访者的现实处境承认他的困难。这就表达了治疗师理解来访者所说的经历，并认为他的话是真实可信的。同时,治疗师继续鼓励来访者坚持之前探讨的行为激活计划。这样治疗师既认同了来访者的看法，同时也帮助来访者找到了解决问题的其他办法，从而可以让他和孩子们保持通信，而这正是来访者高度期望的行为。
 
# 合作(Collaboration)
 
合作的重要性贯穿整个治疗过程。治疗师在行为激活疗法中所做的每件事，从呈现模型到监测来访者行为，再到制订行为激活策略,都是和来访者共同合作完成的。行为激活合作策略可以鼓励来访者在治疗中承担主动的角色，并且通过"团队"合作来和治疗师一起承担责任。例如，每个疗程中治疗师和来访者一起列举行为激活议程中的事项，然后在结束本次治疗的时候一起布置家庭作业。
 
与合作相反的,是治疗师操纵治疗进程,强行制订议程,或者走向另一个极端,对来访者的反应过分被动。治疗师是行为激活疗法的专家，来访者是自己经验的专家。非合作性的治疗则相反,治疗师不能采取合作态度，因而不能注意到来访者在治疗关键节点所发挥的作用。相反，合作态度的治疗师会回应来访者的行为，并会在合适的时候修正行为议程和干预方案。
 
# 非评判性立场(Nonjudgmental Stance)
 
和抑郁症来访者一起工作具有挑战性,特别是来访者不按计划行事，或报告说情绪没有变化。这时候治疗师很容易因为没有进步或者进步不明显等,表现出沮丧或是去责备来访者。在行为激活疗法中，这种情况反而要求治疗师用非评判性和实事求是的态度来回应来访者，既不过分反应，也不要忽视来访者的行为。非评判性立场使治疗师不太可能攻击、蔑视或者批评来访者。相反地，治疗师始终关注阻碍行为改变的绊脚石，并和来访者合作制订更有效的行为计划。在第八章，我们会着重谈谈如何排除障碍,从而以非评判性立场回应行为激活疗法中的挑战。
 
# 温暖和真诚(Warmth and Genuineness)
 
行为激活疗法的核心部分是以真诚的方式表达对来访者的关怀。大多数治疗师认为在治疗关系中容易体验到对来访者的温暖和真诚的关注。强调的态度即意味着治疗师用一般化的风格来传达这些感受，治疗师在对待来访者的时候只需要做自己。另一方面,治疗师没有和来访者达到共情的话会显得冷漠、不关心人。想想看下面的例子,来访者告诉治疗师丧失了某些东西,感觉很难受。


# 反例1-没有共情
来访者：嗯，大概5个月之前，我最好的朋友在上班途中遭遇车祸丧生。我从新闻中认出了她的车，基本上确定那就是她，因为那天我生病在家。
 
治疗师：你非常偶然地从电视上看到了这次事故。
 
来访者：是吧，这个消息给了我当头一击。我马上打电话给我的朋友，警察接了电话并告诉我发生了车祸，然后问我知不知道怎样能联系到她的家人？
 
治疗师：嗯哼。
 
来访者：我不住地回想她去世前的时刻，她那时肯定不知道有多害怕。
 
治疗师：看起来你被这些反复出现的想法折磨着。在这次行为激活疗法中我们要找到另一些做法来代替反复回想那些困扰你的问题。
 
# 反例2-装作关心
 
来访者：嗯，大概5个月之前，我最好的朋友在上班途中遭遇车祸丧生。我从新闻中认出了她的车，基本上确定那就是她，因为那天我生病在家。
 
治疗师：嗯哼，我听出了你声音里的悲伤。这件事一定让你很难受。
 
来访者：那时候非常痛苦，现在也是。我总是想到她，不停地回想她死之前的最后时刻。
 
治疗师：我想经历这些是很让人难受的。
 
# 正面例子-真正关心
 
来访者：嗯，大概5个月之前，我最好的朋友在上班途中遭遇车祸丧生。我从新闻中认出了她的车，基本上确定那就是她，因为那天我生病在家。
 
治疗师：哇，朋友突然意外身亡太可怕了，而在电视上偶然发现这件事情该有多糟糕！
 
来访者：是的，就像是我看到那场车祸一样。我当时马上拨打了她的电话，但是一名警察接到了电话，告诉我发生了什么事。
 
治疗师：你听到那个消息后是怎么熬过来的？
 
来访者：嗯，我当时感觉崩溃掉了。他们问我知不知道怎么联系她的家人。我知道她妈妈的名字，猜想她的手机里存有她妈妈的号码。
 
治疗师：当时你一个人吗？
 
来访者：是的，只有我自己。我没有想给任何人打电话。警察正在忙着处理事故，我想，他们并没有时间翻阅她的手机。我甚至想不起她妈妈的名字，就算我知道。于是我没有打电话给她的家人，警察打了。
 
治疗师：我想象不出来有谁在这种打击之下能够很快想起这些细节。
 
来访者：我不停地回想她死去前的最后时刻，她那时候该有多害怕。
 
治疗师：当然是的，你想象这些应该是很正常的反应。

# 真正关心的好处
当治疗师真诚温暖的时候，来访者更有可能持开放态度。我们更有可能相信一个给予我们合理关怀的人，而不是一个冷漠、虚伪假装的人。这时候，我们常建议心理治疗师回到基本治疗模型和个案概念化，问问自己是不是对于来访者的生活情境或者历史忽略了重要的部分。还可以练习非评判性和保持解决问题的态度。假如治疗师发现来访者令人不快、具有敌意或者难于应付时，可以回忆下来访者是怎样通过条件化作用，形成现在这样的行为风格的。在想到许多难于应付的来访者正面临着生活的困境后，治疗师的同情心会增加。如果来访者不断地挑战治疗师,不完成作业或者不能全身心投入治疗，治疗师可以致力于解决问题，对造成来访者行为问题的影响因素抱着好奇心。最后，来自咨询团队的不断支持，可以让治疗师对来访者保持温暖和真诚的关注，哪怕进步看起来比较慢。
 
# 在治疗中强化适应性行为
 
来访者可能会报告家庭作业的完成情况，或者在谈话中涉及社交活动、锻炼、工作或者家庭责任等。另一些来访者在治疗中表现出适应性行为，顺利完成了作业且在行为活力和参与度方面都有所增加。
 
关于如何强化适应性行为没有标准的处理方法。我们只有在看到行为增加后，才知道行为后果或者奖赏起到了强化作用。对于大多数来访者来说,治疗师的表扬、真诚的热情态度，以及/或者关注都是有意义的强化物。说道:"哇，这太棒了！"或者端坐起来,温和地回应来访者都是积极的强化。例如,之前一度缺乏活力的来访者报告说去市场买了新鲜商品,治疗师既感兴趣又好奇，真诚地回应说:"去商店对你来说是一个不错的转变，做起来困难吗,你怎么做到的呢?"在这里，治疗师会指出他看到了来访者的改变，认识到这种改变需要付出努力，并且通过开放式提问传达出这个改变的重要意义。
 
治疗关键是治疗师必须密切地关注来访者适应性行为或口头报告，持续回应来访者,不断敦促来访者改变其行为。经验丰富的治疗师不会放过任何有价值的事情。一旦来访者提到或者做出适应性行为时，都是治疗师有针对性地强化该行为的好时机。
 
# 艾丽西亚-抑郁行为
 
艾丽西亚每天都觉得沮丧，她都想不起来有哪天不那么抑郁。她总觉得自己焦虑，但她的焦虑相比于她的重度抑郁还不算太令她苦恼，她的治疗师贝丝告诉她，她们会一起来梳理与艾丽西亚抑郁症有关的行为和情境，还有她的焦虑和人际困难。

艾丽西亚觉得这听来很奇怪，她心想：我总觉得很糟糕，区分行为和环境有什么意义呢？我无时无刻不觉得沮丧和担忧。贝丝提醒艾丽西亚说，如果她每天关注自己的经历，或许会发现自己情绪的起伏。于是她们开始详细回忆当天早上艾丽西亚来治疗前的情况，贝丝询问了艾丽西亚的沮丧心情，以及其他和行为有关的情绪。
 
艾丽西亚说她当时步行去杂货店，当她想到杂货店时，心情好像变得逍遥自在起来。但是仅仅就一小会儿，在从杂货店回家的路上，艾丽西亚又开始抑郁，当她回到公寓时，她所有的精力好像都被抽干了一样。
 
 # 艾丽西亚-识别抑郁行为的成分
贝丝听完后，问艾丽西亚在自己公寓时是不是往往情绪更糟，她怀疑艾丽西亚的公寓和最近发生的令她感到痛苦的事有关。当她们继续交谈时，贝丝着重询问了艾丽西亚在公寓里一般会做什么事，她们谈到了艾丽西亚常常躺在床上辗转难眠，或者阅读她觉得“很傻的消磨时间的”杂志。艾丽西亚坦承自己觉得孤独，在公寓里无所事事。
 
她还提到一件平常的事，自从她觉得朋友们就是因为这件事开始疏远她之后，这件事越发让她痛苦起来，那就是艾丽西亚害怕电话铃声响起的习惯。她的电话有来电语音提示，会播报来电者的号码和名字。艾丽西亚很孤僻，以至于每当电话响起时，她都会立刻紧张起来，害怕哪个朋友打电话来寒暄报平安，或者问她是否想参加一场社交活动。如果来电显示是一名推销员，她尽管有些烦躁却会放松下来。如果是一个朋友打过来，她会听是谁来电的，然后将电话的音量关小。当她听不到这个名字时，她会觉得放松一些，直到她删除了所有剩下的信息，她才完全放松下来，她完全不在乎来电的内容。她想着“我会在感觉好点的时候打给他们的”，然后睡一小会儿，最终醒来的时候感到更加空虚和孤独。
 
 
# 评估目标
 
要评估目标首先要对来访者的目标进行一番考察。这很重要，因为行为激活疗法是一种短期的，以行为为导向的治疗方法，要尽早确定治疗目标。行为激活疗法的目标是帮助患者更多地体验到生活中的奖励，并且解决生活中的问题。而具体的目标是因人而异的。
 
评估来访者的目标，需要来访者同治疗师合作。虽然行为治疗强调行为的激活，但是治疗师不能仅仅告诉患者应该忙起来。事实上，大多数抑郁症患者已经听到过这个建议，或者无数次告诉自己“做就对了”。假如他们能直接从沙发上起来去行动，他们早就这样做了，而不用既费力又花钱地寻求专业帮助。因此，治疗一开始有必要问这样一个问题：“患者想要的是什么？”
 
大多数来访者一开始都想让情绪好起来。这种欲望对抑郁症来访者来说可以理解，但很难实现。按照行为模型，只有让来访者增加活动水平，参与到生活当中，最终才有望积极改善情绪。因此，重要的是赶快把治疗目标从想要体验何种情绪，调整为想要做出何种行动、获得何种个人目标。为了追求长期目标，人们会一步步完成许多短期目标。致力于短期目标能很好地让来访者获得成就感和愉悦感。不管来访者情绪如何，朝着理想目标一步步前进，能推动来访者进步并改善其生活处境。
 
 # 借助价值观找到目标
知道一个来访者的价值观是什么，能更好地帮助他们找到恰当的目标。当来访者的诸多目标之间非此即彼或此消彼长时，关注价值观会非常有帮助。价值观是来访者期望的生活追求，它能提供一种方向感，但不像目标能刻意地达到或者获得。人们会不断地按照价值观来行动，在此期间他们会追求能够达成的目标。价值观会引导人们向某一个或者另一个目标行动。对价值观的关注潜移默化地影响着行为疗法。通过考察来访者的目标以及价值观，治疗师能理解来访者想要什么样的生活，从而能够帮助治疗师针对来访者个性化地构建治疗目标。
 
举个例子，某人希望自己能够成为别人的好朋友。比如他最好的朋友请他在周末的时候到家去搬一件很重的家具为来访的客人提供房间，他是那位朋友唯一能够求助的人。然而，当他在周六醒来的时候，感觉自己情绪很低落并且昏沉沉的，他想待在家里，关上百叶窗。他现在有两个互相斗争的念头，一个是帮助需要他的朋友，另一个是摆脱情绪的压力，退回自己的世界中。如果他按照价值观来行动的话，那他更有可能去选择帮助朋友。在这天结束的时候，他会觉得心里好受些，不太可能再退缩和抑郁下去。这样在行为激活疗法中，评估来访者在家庭、人际关系、工作及娱乐等方面的基本目标和价值观会对治疗师有所帮助。
 
# 行为治疗的基础
 
行为激活疗法的第三个原则是指导治疗师怎样评估。这包括考察行为线索，注意行为前后发生的事情，明白哪些重要行为可以对抗抑郁。人们通常都不会注意到不同情境、行为或者情绪之间有何关系。特别是当人们抑郁的时候，就更难发现这种关系了。评估过程能给治疗师和来访者提供这些关系的相关信息，通过这些关系，治疗师可以找到治疗的行为靶点，从而实现治疗目标。
 
治疗师应该如何去做呢？首先，治疗师可以问一些问题，定义和描述来访者遇到的关键问题。第二，治疗师评估来访者行为的线索和后果。第三，一旦治疗师理解了来访者具体行为的线索和后果，就可以开始评估来访者跨时间跨情境下的行为模式。一般来说，理解了这些行为模式，往往就能知道，应从哪些方面加以改变来缓解抑郁。
 
 # 评估行为-ABCs
为了有效评估行为，治疗师可以了解下行为“ABCs”。A的意思是，所有行为都是情境性的，也就是说，行为会在特定情境下发生。我们把这些情境称为“先行事件”，也就是A。B代表我们想方设法理解的“行为”。通常这些行为就是人们来治疗的原因，比如和配偶吵架、留恋有工作的日子、找工作未果等，我们后面会详细讨论如何定义和描述B。最后，所有的行为都会产生一些影响，这些影响就是“后果”，也就是C。
 
# 定义和描述行为
 
我们从B开始。清楚地定义和描述基本的行为问题是非常重要的。在评估行为时，治疗师为了解来访者行为的具体含义，通常需要问来访者许多关于行为的问题。一般来说，将问题看作有待增加或者减少的行为，会对治疗师有所帮助。

一旦治疗师定义并且描述了问题，就要结合原则三来识别来访者的先行事件A和行为后果C。当治疗师理解了来访者的特定行为，就可以构建来访者跨时间和跨情境的行为模式。
 
 ## 需要增加的行为
需要增加的行为包括：一个是使来访者更可能接触到环境当中正强化的行为，解决问题的行为，或者能提高总体生活质量的行为。因为这些行为能够带来成就感或愉悦感，或者解决问题，所以需要得到强化。这些行为可以通过制订活动日程安排来强化。另一个常见的需要强化的行为是积极面对和解决问题。通常来访者会带着一大堆问题来咨询，这些问题让他们无法承受、陷入困境。治疗师应该帮助来访者将各种任务拆分成较小的步骤来完成，再把要完成的步骤按优先度排序，同时学习必要的技能，并承诺要解决问题。
 
 ## 需要减少的行为
需要减少的行为有：给来访者生活带来困难的行为，或妨碍他们满足其他需要的行为。这些通常是逃避行为。此类行为可能是反刍，和当时的心情一致但和目标不一致的行为，或者其他逃避/回避行为，比如酗酒。这些行为通常由于负强化得以维持下来，这些行为使人们短期内可以从讨厌的环境/情境中解脱出来，但长远来看，这样做通常不利于适应。

 
# 先行事件和行为
 
在行为激活疗法中，A和B之间的关系很重要。某些经历会使特定行为更容易发生。我们常常在特定场合下条件性地产生某些感受和想法，这些感受和想法是通过经典或操作条件反射形成的。操作条件反射指的是伴随发生的事件会影响人们的行为。一些事件不需要条件化或者训练就可以引发行为反应。例如，步行穿过田野对大多数人来讲是中性事件。然而，如果一个人在靠近军事训练区的荒野中走了很长一段距离，突然军事训练区传出爆破声，那么这个人以后再来到开阔的荒野时，或许会感到轻微的恐惧。这种恐惧感是由于惊跳反应的非条件刺激(巨响)和荒野的中性刺激伴随出现，使得荒野具有了巨大响声的某些特点，那就能引发焦虑。
 
A和B之间的种种关系，对了解来访者抑郁的情绪非常有用。杰克就是个很好的例子。他成长于工薪家庭，凭着奖学金进入一所贵族高中学校。在校期间，他看到那些穿着华丽的同学似乎比他更轻松地应付学业和社交，并且他们时不时地会因为杰克不知道某个典故而嘲笑他。杰克和他的家人从没出去旅游过，因此，当他的同学们在讨论自己在国外度过夏天时，杰克觉得很羞愧并且显得那么不合群。对他来说，那些穿着华丽的同学成为一种刺激源，使他对自己的失败和缺点产生了消极联想。这种条件化反应会持续到成年期，并在他进入公司管理层后日渐明显。当他和高管一起开会时，仅仅看到那些有成就的同事在场，都会引起他的焦虑和负面想法。即使做出了突出贡献，他也很难在会上大胆发言；不止一次，他静静地坐在座位上，仔细考虑问题的解决方案，而他的某个同事会准确表达几乎和他一样的想法。他和“上流社会”的人在一起时不舒服的感觉，是早在学生时代就被条件化了的，并对他的行为持续地产生影响。随着时间的推移，杰克开始回避这些会议，工作表现也受到了影响，进入了退缩—抑郁的恶性循环当中。
 
我们的感觉、想法和行动，是在特定环境、特定条件下产生的。通常，我们的痛苦或喜悦感是在类似情况下条件化了的(操作性条件反射)，通过体验到后果，我们的行为包括情绪得以保持。梅拉妮3个月大的婴儿在2年前突然离世，当朋友请她抱自己刚出生的孩子时，她体验到了巨大的心理创伤。对梅拉妮来说，同婴儿接近这个先行事件让她比其他时候更容易悲痛。就像杰克和梅拉妮，我们的大多数来访者都经历过各种伴随着痛苦体验的事件。通常我们的来访者会忘记那些情境，忘记那些情境曾带来过的痛苦体验。行为激活治疗师的工作之一，就是理清先行事件和来访者重要行为之间的关系。
 
# 行为和后果-正强化
 
行为激活疗法非常强调B和C之间的关系。当一个行为伴随的后果增加了该行为，我们会说这种行为被强化了。当一个行为获得了满意的结果，那么行为就被正强化了。
 
 # 行为和后果-回避
同样的，我们回避不想要的东西，这种行为也会被学习到。假使一个行为消除了对机体有害的东西，使得类似条件下这种行为更有可能再次发生，我们就说行为被负强化了。例如，杰克通过晚起床和回避此类会议，对参加高管会议时的痛苦感受做出回应。当这样做的时候，他不舒服的感觉减少了，因此晚起及会议迟到被负强化了。不幸的是，经过一段时间，杰克和同事相处的不舒服感觉，会条件性地维持下来，而不是通过大胆陈述自己的想法并体验成就感和掌控感，来对抗这种不舒服感觉。
 
 # 行为和后果-惩罚
行为还可能会被惩罚。每当行为的后果减少了该行为在类似情况下再次发生的可能性时，不管这种结果意味着坏的事情发生，还是好的东西不见了，我们都说这种行为被惩罚了。因此，如果杰克想要在会议上大胆发言，而高层的同事用嘲讽的语气回应他，杰克的自信行为就会受到惩罚并且降低再次发生的可能性。类似地，如果杰克大胆发言的结果，是目标职位随后被指定给其他人，那杰克以后也会更少大胆发言。
 
 # 行为的功能
行为的功能指的是该行为带来的后果，比如伴随一个行为的强化或惩罚。行为激活疗法非常关注行为功能，我们更感兴趣的是行为的功能而不是行为的方式，或者行为看起来是什么样的。
 
达伦的例子就很好地证明了行为的功能重于形式。他的妹妹艾米在他15岁时骑车到路口中间时，被车撞死了。妹妹死后，达伦的妈妈患上了抑郁症。他从贵族学校荣誉毕业后作为高管开始成功的职业生涯。他在38岁时事业有成，拥有了幸福的婚姻，并生了一个女儿。
 
除开抑郁的时候，他花了很多的时间来陪女儿玩，通常会去享受一些户外活动。他们总是一家人一块儿去骑车。在旁人看来，这些丰富多彩的家庭活动能改善他的心情和幸福感，并且对他家庭的生活也有帮助。然而，达伦不许女儿在其他任何时候骑车。周末骑车成了一种强制的行为。但这样才能让达伦对女儿自己骑车不产生焦虑，同时也让他不会在看到女儿在街上骑车时，再次体验到因妹妹死亡带来的悲痛。当达伦的行为看起来像一个好爸爸时，骑车这件事的实际功能，是减轻他对女儿可能会遭遇意外的恐惧，并减少他对妹妹的死以及妈妈后来患抑郁症产生的愧疚感。因此，这种行为的功能，是微妙地回避了和多年前他妹妹死亡时类似的情境所带来的消极情感。

# 监测活动
 
当指导来访者记录活动时，治疗师要引导他们在记录太多或太少间找到一个平衡点。来访者实际上不需要在每小时都记录太多繁杂的信息，但信息要足够，好让治疗师和来访者都知道当时发生了什么。通常当来访者开始监测，他们会记录宽泛的条目和大块的时间。例如，他们可能会写“上班”8小时，他们会描述自己的心情是“无聊的”，持续的时间是“8”小时。这样记录的问题是，他们不能注意到隐藏在变化当中的有价值的信息。当一个人经历了一个“糟糕的工作日”，通常并不是每小时每分钟都很糟糕。“上班”这项活动事实上是由更多的具体活动构成，并且这些活动通常有重要的记录价值。或许和同事在咖啡店里的聊天很享受，但阅读不完的电子邮件却很无聊，而阅读一封关于即将开始的项目的邮件，相对于通报时间节点的新任务邮件更加有趣。虽然指望来访者每读一封邮件后记录下情绪是不现实的，但是可以想见来访者记录咖啡店的聊天带来的“投入”和读完电子邮件后的“无聊”，比泛泛总结自己一天的工作为“无聊”，能提供更多有意义的信息。我们期望来访者能像上面所说这样详细地监测自己的行为，因为从行为活动表的情绪变化可以帮助我们认识到哪些活动和抑郁情绪有关，哪些活动能改善情绪。量化情绪的变化，能帮我们发现要增加或减少哪些活动。这样监测才能帮助治疗师发现具体的治疗目标。
 
# 监测内在活动
对一些来访者来说，记录内在的活动也很重要，比如反刍。举个例子，一个来访者在记录“同一个邻居谈话”时，同时将心情记录为“绝望”。在得知这些信息后治疗师就可以了解这位邻居是否让来访者感觉有压力。但是，通过进一步的调查，治疗师可能会了解到，来访者和邻居在聊各自家里的草坪时，来访者在聊天过程中反思自己过去有多么喜欢他家的草坪，而现在由于患上抑郁不再关心这件事。在这种情况下，重要的是要将“反刍”当作一种行为，记录在活动记录表上，因为这样可以更加精确地描绘出和绝望相联系的行为模式(这个案例中是反刍)。和邻居讲话固然是来访者经历的重要部分，但来访者内心的活动(反刍)才是案例的核心本质。
 
# 监测心境或情绪
 
在指导来访者记录他们的心境、情绪及其对应的强度时，开始可以先从某种情绪开始给情绪划分等级，比如将抑郁情绪用“1”(表示一点也不强烈)到“10”(非常强烈)10个数字表示。当来访者逐渐熟悉活动记录表，并且熟练地观察自身的情绪体验后，就可以鼓励来访者记录一系列具体情绪(比如悲伤、愤怒、快乐、羞愧、厌恶、担忧等)及对应的强度。一些来访者在识别个别情绪时感到困难，这时治疗师就有机会教授和训练来访者的行为技能。如果要获得更多关于具体情绪识别的信息，治疗师可以去查阅辩证行为治疗手册中关于情绪调节技能的训练模块，该手册提到了悲伤、快乐、恐惧、愤怒、羞愧、厌恶和惊讶等情绪。
 
# 监测掌控感与愉悦感
 
如果不监测情绪，来访者还可以记录活动带来的掌控感与愉悦感。掌控感是一种体验到成就的感觉，愉悦感是伴随活动的快乐感觉。给这些维度进行等级评分，可以监测活动的功能是强还是弱，也就是说，能带来的掌控感或者愉悦感是多少。掌控感与愉悦感的强度同样也用10点量表来记录，“1”分表示掌控感或愉悦感低，“10”分表示掌控感或愉悦感高(见附录Id)。
 
# 监测强度
 
治疗师可能还会让来访者指出哪些时候有不同程度的悲伤，以便帮他检查和情绪变化有关的那些活动。这时候帮来访者用生活中的真实活动，标定情绪最强和最弱的时候，是很有价值的。例如，当艾丽西亚的治疗师第一次给她介绍情绪监测的时候，她同艾丽西亚一起寻找哪些活动的情绪强度最高，哪些活动的情绪强度最低。当用0~10的等级来表示抑郁情绪时，阅读娱乐流行杂志时的情绪只得了较低的“3”分，而收听语音信箱的留言时得了“10”分。类似的，当评定掌控感时，读杂志只能带来微弱的掌控感(强度为“1”)，而阅读一章关于园艺方面的书能带来最强的掌控感(强度为“10”)。在评定强度时，治疗师可能会发现一些来访者不喜欢用数字来分级。这时更合理的做法是采用词语来描述强度等级。例如从“一点点”到“很严重”。还有些时候，来访者甚至可以用一些其他符号表示他的情感等级。
 
最后，设计一种清楚明了的方法来说明具体活动的效果。因为所有监测方法的最终目的，都是为了弄清楚特定活动和来访者的感受、行为功能(掌控感/愉悦感)之间的关系。只要持续监测活动和所处的情境，那监测就会有用。

# 活动监测的回顾
 
当来访者完成了疗程中间的活动监测作业后，治疗师要在接下来的疗程中花一些时间来回顾活动监测表。在回顾中，治疗师可以大声读出来或者要求来访者大声读出来。在讨论一开始可以询问来访者从作业当中学到了什么。来访者可能已经注意到了行为模式，并且对活动是如何带来情绪体验的有些头绪。治疗师接下来可以和来访者一起回顾活动监测表，共同探讨其他可以作为治疗目标的行为模式。
 
# 有效促进回顾的几个问题
 
帮治疗师认识哪些活动或行为导致抑郁症状的维持。尽管没必要问到所有的问题，但记住这些问题，能帮你更好地理解来访者的行为模式。
 
## 问题1：来访者的活动以及情绪间的联系是什么？
这类问题可以帮助治疗师建立假设，哪些活动和来访者抑郁的持续有关。最重要的是，注意到情绪是如何发生变化的。来访者和治疗师一开始可能会讨论与特定情绪相联系的行为模式。比如像“你能告诉我这周在记录的时候注意到了什么？”这样的问题有助于启动谈话。理解哪些行为会或多或少使来访者抑郁，以及情绪在什么情况下发生改变，这是非常必要的。贝丝和艾丽西亚一起注意到了艾丽西亚抑郁的情境因素，比如艾丽西亚有天在社区的豌豆田工作时觉得情绪低落，而另一天则觉得快乐。到底是这两个活动中哪些方面造成了情绪有所不同呢？留心那些和积极情绪相联系的活动，能提示来访者应该增加哪些行为。
 
 ## 艾丽西亚的活动与情绪间的联系（一）
 
贝丝：是这样，我看到你在之前一个小时记录的是，工作之后沏了一杯茶并觉得“心满意足”。当你在花园工作时，你觉得发生了什么让你的情绪发生了变化？
 
艾丽西亚：我觉得可能是当时的时间，当时外面天已经有点黑了，如果我没记错的话，阴暗的环境还有绵绵细雨让我觉得有点悲伤，我想享受花园里的一切，但我摆脱不了阴暗，我觉得必须得赶在太阳完全落山前做完手头的事。当我返回公寓时，我觉得房子里特别黑，这也影响了我的心情。
 
贝丝：所以，天气对你来说真的很重要，它能影响你的心情，特别是阴天。
 
艾丽西亚：是，还有如果我没有照到一丁点太阳时，就很害怕回到公寓。周二要好些，我觉得出去要早一点，天气也要好些，我在外面也待得更久些。
 
贝丝：对，实际上你周二“在花园里工作”了好几个小时。周一你是因为阴天而感到悲伤吗？
 
艾丽西亚：不，是因为我讨厌待在公寓。当我在花园里时，我一般感觉都很好，大多数情况下，我一个人待在那儿，周一那儿还有其他人，他们有点吵。我自己倒很安静。当我一个人在花园时，我有时会唱歌给自己听，感觉真的很好。我还会看看周围正在生长的植物，但其他人去会让我有点烦，所以我只待在一小片地方。

艾丽西亚：是的，周二下午一开始20分钟只有我一个人在那儿，过了一会儿，另一个女人来了，但她很友好也很安静。她和我打了招呼，并且在花园另一处工作。她从我旁边经过时，她点评说一些植物长得很美，还聊了会儿花园有多么可爱啊。

 ## 哪些行为能得到来访者信息
问到哪些活动和比较消极的情绪有关之后，治疗师和来访者就能讨论这些活动存在的问题，它们并不一定是需要减少的行为，因为治疗师首先要明白活动的哪些方面带来了糟糕的情绪。很明显，艾丽西亚和贝丝需要一起学习的还有很多，贝丝可能还要询问以下问题。比如：艾丽西亚在花园中和别人谈论了什么？豌豆田中其他人通常会怎么做？贝丝可能会针对艾丽西亚和不同的人交往问些类似问题。艾丽西亚是不是无意中惩罚了别人的谈话行为？她是否回避与人长时间交谈，所以给别人留下很难接近的印象呢？
 
观察和情绪变化有关的行为也能得到来访者的重要信息，比如睡觉、饮食、工作等作息规律有没有被打乱，作息管理是开始治疗的有效策略。父母及行为激活治疗师都知道，如果没有充足的睡眠及营养，很难应付生活中遇到的问题。逃避工作能导致许多问题，这些问题会使来访者的抑郁加重。一般来说，回避是行为激活疗法中需要评估和干预的基本行为模式。因此，我们可以用活动监测法评估下面第二类问题。
 
## 问题2：在一周当中来访者的整体情绪状态如何，具体情绪体验又如何呢？

来访者会参加各种各样的活动但往往体验到的情绪变化并不大。让来访者用活动和情绪记录表记录下各种情绪，可以让治疗师观察到情绪的变化。当来访者报告完一周内的情绪，治疗师就能回顾特定的活动和情绪之间的联系，从而初步推测哪些活动该增加，哪些该减少。当来访者只报告一两种情绪时，治疗师还可以另外评估下其他的一些情绪。出现这种情况，一个原因是来访者缺乏能力去识别和描述某一时刻的情绪体验，可以考虑是不是有这种或者其他可能性。
 
# 问题3：来访者的作息规律有没有被打扰？

通过回顾活动监测表，就可以大概了解来访者一天或一周的作息。假如来访者睡眠时间发生大的变化，或者吃饭时间随意改动，治疗师可能就该担忧了。抑郁中的来访者可能会脱离日常作息。因此，行为激活疗法的另一个聚焦点是帮助来访者调整作息(Martell et al., 2001)，改为正常作息。作息时间规律、可预测，能帮助来访者有条理地做事情，并专注于手头的工作。当日常作息被严重打乱，有时会让人承受不了。举个例子，设想某人丢了工作，那么他原先有序的一日生活突然会被过多的空闲时间填满。再想想看一个人下班回家放松之后然后上班，或者是在繁忙的出差或者假期后躺在自己的床上。回到正常的生活作息很舒服，但当一个人患上了抑郁，正常的生活作息就会被打破，他就会觉得不舒服。我们并不是说抑郁是由于生活规律被打乱导致的，但是有文献报道显示，社会生活失去规律会导致重性抑郁发作，或双相抑郁的躁狂发作。
 
# 问题4：来访者存在什么样的逃避模式？

最好知道来访者在生活中回避哪些情况。有时逃避表现得非常明显，比如来访者早上赖床。但有时回避不容易看出来，比如来访者回避让自己觉得羞愧的情境。这就需要知道是什么妨碍了来访者投入并享受生活，因为回避会导致被动，从而使问题悬而未决甚至恶化。活动表可以提示来访者生活中需要解决的问题。回避模式和情绪间的关系可能会比较微妙，因为来访者的回避有时能让他们感觉更好。事实上，对大多数人来说，这就是他们会回避的动机。通过回避，他们的情绪放松了下来，甚至感到愉快。思考一下艾丽西亚的例子，在这个例子里回避社交事件让她的情绪得以放松。
 
## 艾丽西亚-回避社交
艾丽西亚：我不知道为什么，但就是不想参加我朋友图书俱乐部的第一次聚会，哪怕我原本计划要去的。
 
贝丝：是最后一刻才决定不去的吗？
 
艾丽西亚：是的，我甚至仔细考虑过穿什么去，还特意去挑选了一件套装。
 
贝丝：接下来发生了什么？
 
艾丽西亚：当我想到自己在图书俱乐部谈到书，从来没有说对话，就开始感觉不好了。其他人都那么聪明，而我却有点傻。所有的不安都涌上心头了。
 
贝丝：在你参加图书俱乐部前，发生过这些事儿吗？
 
艾丽西亚：偶尔会，但其他人通常都很亲切，而且我知道朋友只邀请待人亲切的人。但那天我就是不想去。我觉得羞愧和自责，我好像浪费了自己的生命，没有花时间阅读，没有更多地了解世界，好让自己也变得能言善辩。当我决定不去以后，我就放松了下来，待在家里觉得很开心。
 
# 问题5：来访者应该从哪里开始改变呢？

当我们知道哪些活动有助于改善情绪之后，就需要明确当来访者无力行动时，哪些活动做起来更容易。类似的，我们还要明确该减少哪些活动，而这些活动和负性情绪或者回避有关。明确这些活动后，就一步步地减少回避行为，可以减少这些行为的数量(比如从一晚上喝四杯酒减少到三杯)，也可以减少浪费在无所事事回避上的时间。对于一个每天花将近5个小时来打游戏，分散注意和回避的来访者，要求他们将每天打游戏的时间缩短到30分钟，同时做其他更有用的事，至少一开始是行不通的。但如果和来访者合作制订一个计划，适度地减少他每天的游戏时间，比如前两晚各减少10分钟，接着第三、四个晚上再减少10分钟，这样做更有可能成功。循序渐进的原则同样适用于带来消极情绪的行为。贝丝注意到艾丽西亚说在去杂货店的路上，情绪已经有轻微的好转了，但之后她的心情又变糟了。这里，第一步是需要增加行为。

# 有效选择活动
 
行为激活治疗师一般来说可以针对两种活动或行为来减轻抑郁症状。有些活动需要增加，因为它们能改善心情及生活环境；有的活动需要减少，因为它们会维持抑郁心境并且让生活变糟。来访者们通常会对这些要增加或减少的活动表现出不同程度的偏好。由于行为目标多样，最好将能快速产生效果的行为作为目标。当我们和抑郁来访者讨论行为激活模型时，我们通常会从那些暂时缓解压力的行为开始——尽管不能完全摆脱抑郁情绪——这就是所谓的“次级问题”。我们努力在短期内打破行为导致抑郁的恶性循环，然后再帮助来访者花更多时间来做出长期改变。例如，来访者可以首先通过增加体育活动和社会交往明显改变其抑郁心境，然后再努力完成找工作的远期目标。

# 如何激活来访者
 
大部分抑郁的人都能够意识到增加活动会有帮助。实际上，许多人也无数次对自己说“去做就好了”，或者别人这样告诉他们。行为激活疗法的悖论就在于治疗师让来访者去做的事情恰恰是来访者感到最困难的事情。退缩、无精打采、缺乏兴趣和愉悦感都是抑郁症的症状，而一个旨在改变情绪体验的疗法又是怎样开展的呢？这个难题也正体现了行为激活疗法面临的希望和挑战。需要结合原则一，原则
 
## 原则一：改变人们情绪体验的关键是改变行为方式
 
正如我们所说，负性情绪自己就带有一种能量，原则一概括了行为激活疗法的主要目的，也就是帮助人们通过行为来调整情绪。当我们感觉情绪低落，一个人的所作所为更有可能让情绪继续低落下去。情绪低落容易引发与其相应的行动。大多数行为激活疗法都会要求来访者根据计划或者目标，而不是情绪或者内部状态来行动。我们在推荐行为激活疗法的时候，往往强调负性情绪的本质，并要求来访者考虑由外而内行动，而不是由内而外。抑郁症患者假如不能从行动中获得愉悦感，疲惫而无精打采，那么他就不太可能参与曾经喜欢的活动。行为激活治疗师要做的是扭转这种局面，要求来访者由外而内行动，也就是说根据目标或者计划而不是根据情绪来行事。比如，哪怕没有兴趣，也要让抑郁的来访者参加以前喜欢的活动，或者多做些其他活动，因为“快乐总会回来的”。由外而内的行动目标，是让来访者接触到环境中的积极奖励，并化解抑郁情绪带来的负能量。
 
### 来访者的担心-假装
一些来访者担心由外而内行动就是要他们假装。某种程度上是这样的。行为激活疗法的策略，就是要求来访者根据计划来行动而不是根据心情，因此看起来会不自然、“做作”。可以想象一个右撇子的右胳膊断了，需要借助左手来完成日常事务。整天用一只手来做事很笨拙，而且还是用非利手。这个人会讲当他用左手笨拙地泡咖啡、用电脑的时候，甚至觉得都不像是自己了。因为这时候他需要比受伤之前更努力、更专注。慢慢地，他就会更熟练，使用左手会更容易。随着胳膊逐渐痊愈，最终两只手都可以用了，并且一如往常。这个比喻巧妙地描述了我们要求抑郁症来访者所做的事情。要求他们笨拙地、努力地、甚至不自然地行动，由外而内改善情绪，直到抑郁减轻。一旦情绪好转，他们会更轻松自然地投入日常活动。
 
### 来访者的担心-由外而内的困惑
另外一个常见的关于由内而外行动的困惑是，来访者认为抑郁症是生物性的。这些来访者会怀疑行为取向的治疗方法能不能解决实际上是生理因素导致的抑郁。许多抑郁症患者正在服用或者服用过抗抑郁药物，并且或多或少有效。还有来访者想知道是不是服药会更有效。行为激活治疗师可以向来访者证明许多方法都可以治疗抑郁症。
 
临床随机试验已证明，行为激活疗法和认知疗法或抗抑郁药物的疗效相同或者差不多。认知和行为干预比单纯服用抗抑郁药更能长期预防抑郁的复发。让来访者知道行为激活疗法比药物治疗的长期效果更好，对治疗是有帮助的。
 
# 行为激活的生理基础
相对于安慰剂组，或者运动“剂量”较小的实验组而言，当被试按照美国运动医学院制定的运动标准每周至少锻炼3~5天后，该组被试的抑郁症状大大减少。老年被试参加身体锻炼后，抑郁症状有中等程度的减轻。锻炼身体比参加社交活动更能够改善抑郁。在不考虑此前的身体和心理健康水平时，中年女性的运动增加和抑郁症状减少有关。这些研究提供了更明显的证据，即改变行动就可能改变情绪；产前和产后的生活经历无疑会塑造大脑的结构和功能，并对人的行为和思想产生重要影响。生活经历和活动可以影响生理学症状。行为是具有生物学属性的，生理状态也会受到行为的影响。“长期坚持身体活动可以改善大脑健康”。研究者指出，动物研究表明身体活动会促进大脑分泌更多生长因子，影响神经发展，刺激神经元的生长和发育，预防海马神经元生成中的缺血性损伤和新纹状体的神经毒性损伤。
 
人类的临床研究也指出，不经药物或者药理学干预也可以改变脑的化学状态。发现行为治疗起效的强迫症患者，相对于行为治疗无效的患者而言，大脑和葡萄糖代谢有关的脑区发生了改变。同时，社交恐惧等其他心理问题的认知行为疗法治疗也显示了类似的神经机制。
 
# 行为激活 vs 药物
行为激活疗法的短期治疗反应优于认知治疗，并且2年追踪研究发现行为激活疗法的来访者生存期和认知治疗的来访者没有差异，相对于24个疗程或者更短疗程的认知治疗或行为激活疗法，抗抑郁药物治疗起效的来访者停药以后复发率更高。尽管没有观察行为激活疗法效果的脑活动，我们推测行为激活疗法引发的行为改变对神经活动的影响应该类似于认知行为疗法。行为激活疗法鼓励来访者增加活动——从复杂的工作或者家庭活动到简单的身体锻炼。来访者应被鼓励采取主动的态度进行有效的问题解决，而不是仅仅反复考虑这些问题。来访者还应当去积极行动而不是消极回避。
 
持续的每日激活是心理及生理健康的保护性因素，对于青少年、成年人和老年人身心健康休闲活动尤其有益，可以增强他们面对生活压力和日常琐事的应对能力。住在香港养老院的老人如果能料理自己的生活和参与休闲活动，相对于不能参与这些活动的老人生活满意度更高。
 
治疗师在尝试行为激活疗法时应当参考这些基本知识。可以鼓励来访者认识到有许多科学研究支持行为激活改变情绪的治疗模型。在有了这些知识之后，治疗师和来访者可以着手确定最应当关注的那些活动，以及明确如何由外而内地发挥治疗效果。
 
# 原则四：按照计划而不是情绪来组织和安排活动
 
行为评估可以帮助治疗师和来访者合理可靠地选择特定活动作为目标。之后就是安排和组织活动。活动日程安排的制订原则是，明确活动的具体时间（有时是地点）来帮助激活最大化。并不是所有的行为激活任务都涉及日程化，例如与来访者约定好在下一个疗程前给朋友打电话，就不需要设定具体日程。很多来访者有意图去做事情但是会任由情绪支配行动，从而妨碍计划的顺利实现，所以制订活动日程是很有帮助的。制订日程指的是设置一个来访者承诺做某项活动的具体时间，并为来访者提供行动方便的参照点，而不是根据来访者当时的情绪体验如何来行动。合适的话，治疗师和来访者会约定活动持续的时间。活动结构化指的是用行为学的术语定义来访者将要做什么，在哪里做，是否有其他人参与，如何量化行为有无成功等。
 
## 规定任务发生的频率
 
来访者常常会高估他们能做到的事情。具体任务的频率需要遵循循序渐进的原则。例如来访者表示想要开始慢跑，并计划在下一个疗程之前每天都做。尽管在来访者患抑郁症之前这个频率容易达到，但是对当前来说可能是个挑战。行为激活治疗师的目标是，首先指导来访者设定一个能够激发彼此信心的活动。治疗师可以建议来访者每周跑步一次。来访者可能会计划跑一次，但是希望能跑上三次。这是个好的开始，因为来访者总能够做得比计划更多些。下一步就是确定活动强度和持续时间。
 
## 规定任务持续时间和/或强度
 
设想一下詹姆斯的情况，这位来访者带回家的作业是每天散步一次，连续3天直到下一次约会开始。这个作业有什么局限？当然了，看起来这个办法能够让来访者保持活跃，活动次数也很清楚。但是这个作业不具体，无法有效指导詹姆斯的活动。治疗师可以这样思考，关于与来访者达成的约定，作业能否提供足够的信息？行为激活疗法特别重视行为的具体化。詹姆斯是不是同意每周有3天散步，每次走2小时、10分钟或3英里？如果以前詹姆斯走3英里需要45分钟的话，那么设定20分钟内走完，每周三次是比较好的。
 
## 规定来访者做活动的日期和时间
 
经过再三回顾来访者活动表，治疗师开始清晰地认识到来访者最近的活动范围。这时候治疗师以及来访者就会进一步确定哪些日子和时间完成活动的可能性最大。詹姆斯同意每周用三天时间来散步，并且透露说他更愿意在新的一天刚刚开始，趁着自己的精力还足够时去散步。首先，治疗师将考虑詹姆斯需要几点钟上班，要提前多久离家去散步，以及一大早醒来的第一件事就是去散步是否可行。假如来访者觉得起床上班都困难，就更不会早起1小时来散步20分钟。詹姆斯可以接下来决定哪天散步更适合工作进度表。
 
# 原则五：从小处着手，改变更容易

在治疗当中从小事做起，逐渐增加难度，然后一直鼓励来访者。分级任务指的是先从简单的活动开始，然后逐渐增加复杂性和难度。也就是说，循序渐进地设定活动，从简单到复杂，用这种方法设计活动可以让来访者在一开始努力的时候就获得成功。这样做的原因是确保在治疗中体验到奖励，而不是在起步时就因难度过大而放弃。如果来访者认可“行动滋生更多的行动”，那么开始的成功就会带来成就感，从而使来访者更愿意完成接下来的任务。
 
当人们挑战具体目标而不是模糊目标时表现更好。此外，相比长期目标，近期目标通常伴随更好的表现。知道目标如何实现，包括什么时候、在哪里、如何行动，也是达成目标的关键因素。拥有提升目标的人，会关注有没有积极结果，相对于拥有预防目标的人更有优势，更能够促进目标达成。以上发现提示我们治疗师和来访者应该如何组织活动。
 
此外，要从基线水平开始完成分级任务。要从来访者当前能够完成的任务开始，而不是从来访者觉得自己应该完成的任务开始。假如来访者已经在抑郁中挣扎很久了，就需要较长一段时间才能做出改变。
 
 # 艾丽西亚-从小事做起
 
当艾丽西亚决心同朋友开始联系时，贝丝需要记住从小的方面做起，并且尽可能地细化任务。
 
贝丝：我们已经谈过你要联系朋友这事儿了。
 
艾丽西亚：是的，我不能一直躲着谁都不见，这样我真的要变成孤家寡人了。
 
贝丝：当你想联系朋友时是怎么做的？
 
艾丽西亚：要是在早晨，我就会在床上翻来覆去、躺着不起，非常累、情绪非常低落；在晚上的时候，我就会找些别的事情做，但就是不会打电话。
 
贝丝：你有尝试过打电话或者和朋友见面吗？
 
艾丽西亚：没有，完全没有，自从和艾伦聚过之后就没有了。我好像朋友很多，但和朋友聚会我觉得很累。我认为应该见见一位亲切的女性同事，她想要认识我。还有我已经大概5个月没有和鲍比说话了，上个圣诞节之前鲍比就说过想和我聚聚了！我觉得我需要见见鲍比。
 
贝丝：艾丽西亚，如果这些事全做的话，听起来有点多。
 
艾丽西亚：……还有我的兄弟姐妹。想到刚才说的这些事我真想躲进一个洞里。

 贝丝：我觉得关键是从什么地方开始。我知道这真的很难。你一直以来都面临很大压力，解决社交问题可能需要花些工夫。但是我相信我们能解决这个问题。除了和艾伦一起喝咖啡，我想请你不要强求自己做更多事情。

贝丝：我很想知道你还能做哪些事情。你可不可以列出一些具体活动来重建社会关系？然后我们看看从哪里着手。
 
艾丽西亚：好。

贝丝：有道理。我也很喜欢这个主意，因为先联系艾伦最有可能让情绪好转起来，对吗？

贝丝：如果你第一个目标定的是下周同艾伦见个面，会怎么样呢

贝丝：嗯，说得好。好像我们还能细化下任务呢！那找个下午邀请她和你一起喝杯咖啡怎么样？
 
艾丽西亚：我想能做到吧。

# 怎样分解社交任务

贝丝和艾丽西亚探讨了怎样分解社交任务。有时候，看起来来访者难以完成简单任务，实际上一开始就做了很多复杂的任务。比如，艾丽西亚可能会先和艾伦通电话，接着又在那一周重新联系了她的朋友鲍比。细化任务对治疗师和来访者来说都是需要创造力的。一些任务是较为直观的，比如打扫房间的卫生和付清逾期的账单。还有些任务，如建立人际关系或是遭遇亲人的离去，就相当复杂了。然而不管任务有多复杂，目的都是让来访者开始做一些事。很明显，只和一个朋友聊天是不可能缓解抑郁的。然而行为激活治疗师一遍又一遍地重复这项“千里之行始于足下”的原则，做一点点的改变就可能带来成就感和微弱的希望，使来访者更有可能继续挑战一些前所未有的困难以及生活中的重要方面。这在解决复杂问题时尤为重要，不管这些问题是来访者的抑郁带来的还是生活环境造成的，比如说工作很难找的时候，而求职过程又会维持或者加重抑郁。
 
 # 可能遇到的问题
许多来访者会辩解说觉得进步太缓慢了，要做得更多才行。除了“我能做（任何事）”这种不现实的想法，还有的来访者会对哪怕最小的任务都说“我做不了”。强调从小事做起往往能让这两种极端的人轻松完成任务。当一个人抑郁时，制订一个详细的分级任务作业非常有用。

在所有的这些方式中，行为激活治疗师会根据来访者的精力、时间和资源来决定来访者应该做出哪些改变。利用分级任务改变行为的同时要求来访者和治疗师有耐心和毅力。表5.2提供了2个额外的例子，说明治疗师和来访者是如何在生活中的重要领域做出改变时分解任务的。
 
## 分级复杂任务（一）

与朋友重新建立联系
 
· 制作一份与来访者失去联系的人的名单。
· 尽可能收集这些人的电话号码或者是电子邮箱。
· 选择一个或者两个人联系。
· 选择一个日子，一个时间，一种方法与他们联系。
· 打电话或者是发电子邮件。
· 邀请他们见面。
· 选择另外一位老朋友。
· 重复再做。
 
## 分级复杂任务

改善来访者不满意的、压力巨大的、项目进度滞后的工作状态
 
· 列出所有的工作项目。
· 记录每个项目的截止日期或项目是否顺利进行。
· 将一个项目作为未来几周的工作目标。
· 确定该项目包含哪几个部分。
· 记录项目每个部分大概所需时间。
· 每天早上安排其中一个部分的任务。
· 监测完成项目所花时间、实现的目标和遇到的障碍。
· 下一次治疗对行为监测表进行扫除障碍并选择下一个项目作为新目标。
 
 
# 反对全或无的激活方式
 
安排和组织活动可以对抗来访者的回避行为，并帮助其激活行为。但是这样做的目的不是一定要做完一项任务。许多抑郁症来访者容易因为无法忍受失败设立了一些不切实际的目标。所以设立活动应当使成功最大化。假如约定的作业是在这一周给某两位朋友打电话或拜访他们，那么即使和其中一位朋友在电话上交流过一次也应该看作一种进步。有时候做完一项活动可以马上改善情绪，那么下次就会更容易再次尝试这项活动。有时需要鼓励来访者坚持做下去，治疗师可以这样宽慰来访者：要是活动选对了，哪怕不能马上得到回报，但是终究会有回报的。这种情形常见于下列活动：比如打扫一间屋子、写一份履历以及诸如此类的杂务。当看到园子里不再胡乱堆砌叶子的时候，来访者可能会开心，也可能不会。而且有的来访者甚至并不乐意在户外做事。尽管如此，随着时间过去，不断做更多的园艺工作可能会带来愉悦的体验。另外，除了带来愉悦感的活动，行为激活疗法还包括了参与带来掌控感的活动，掌控感对促进行动的价值不可小视。例如，或许来访者并不享受园艺工作，但他在完成任务时得到了满足。此外，就是小小的进步也应该得到奖励，即便奖励并不那么显而易见。总的来说，行为激活疗法是基于这样的假设：只要不断坚持小的进步，来访者终究会步入正轨。
 
# 原则六：强调行为的自然强化
 
当人们的行为在环境中自然而然地得到强化时，其再次发生的可能性远高于随意地获得与所作所为无关的外部强化，例如给小孩子糖以奖励他们洗澡。自然强化指的是对行为的强化是行为合乎逻辑的结果，且该强化原本就存在于环境中。例如，当某人看见厨房很脏而去清洗餐具，因为这能给他带来一种成就感和愉悦感，从而洗餐具的行为就可能会增加。这种掌控感以及愉悦感是自然的强化物，从逻辑上伴随洗餐具的行为而发生。相反，如果某人将洗餐具仅仅视作一项家务，并且觉得整个过程是很讨厌的，但却在完工后受到了款待，那么就会偶尔洗洗餐具，但不一定会比以前洗餐具的行为更多。

因此，有经验的行为激活治疗师会分辨哪些行为可能带来自然强化。什么样的活动会伴随自然强化，线索就在来访者过去的生活中。简单地询问“当你不抑郁的时候你可能会去干什么？”有助于发现这些活动。
 
 ## 艾丽西亚-自然强化
如果艾丽西亚的朋友艾伦在接电话时说：“你很久都没打电话给我了，我还以为你从地球上消失了！”艾丽西亚也许会感到羞愧，对给艾伦打电话这件事感到失望。然而如果艾伦回说：“艾丽西亚，接到你的电话实在太好了，我一直想着你并且想给你打电话，真高兴你先打过来了！”艾丽西亚可能感到被接纳、感到开心，并且更愿意下次再打电话给艾伦。这就是自然伴随的事件，而艾伦的支持就是自然强化。
 
# 利用自然强化-管理行为的“ABC”
 
利用自然强化的办法之一是管理来访者生活中的依随事件。依随性管理指的是在某些条件下管理活动的结果，也就是管理行为的“ABC”。例如，治疗师可以鼓励来访者公开承诺参加某项活动。像前面提到的那位来访者詹姆斯，他答应在下一周要抽出三次时间散步20分钟，我们就可以鼓励他和朋友一起走而不是独自行动。答应和朋友一起散步就是一种公开承诺，可以通过和其他人共同完成活动体会到更多愉悦感。在有些时候，治疗师和来访者也许会同意来访者在每一项任务完成后都给治疗师打个电话。这可能是为了达到两个目的：因为在向治疗师报告顺利完成任务时来访者得到了成就感，所以行为可能会得到强化；因为来访者不想向治疗师承认自己失败了，所以逃避行为可能会得以减少。
 
 # 利用自然强化-普雷马克原则
另一种依随性管理的方法是用普雷马克原则，即规定要想来访者做出高频率行为，就要先做某种低频率行为。换句话说，如果看电视是高频率行为而打扫厨房是低频率行为，个体安排看电视就要先花些时间打扫厨房。这种方法也遵循了参加自然强化活动的原则，但它采用了其他的刺激物来促使个体增加没得到充分强化的活动。不可否认的是，这里的强化活动是任意指定的，因为在我们的例子中，看电视并非清洗厨房的直接结果。不过，枯燥或困难的工作也可以通过管理环境依随性事件变得更容易。比如洗衣服时听音乐会使洗衣服变得更有趣。给任务分级，从能够快速完成的一项任务入手，可以立即获得掌控感，从而对于攻克耗时的或困难的任务有更强的动机。依随性管理，安排活动，以及设立来访者可以达到的行为目标，都是在行为激活疗法中贯穿始终的技巧。
 
# 行为激活疗法中组织安排活动的策略
 
当帮助来访者组织和安排活动时，记住这些策略会对你有所帮助：
 
1. 什么样的活动频率对来访者最有效？
2. 什么样的持续时间和/或强度对来访者最有效？
3. 来访者应该在什么日子、什么时间来做这些活动？
4. 你和来访者可曾从小处着手？
5. 你和来访者可曾对抗过“全或无”的行为激活方式？
6. 你和来访者可曾识别过那些可能得到自然强化的活动？

# 艾丽西亚-回避
 
贝丝一边仔细地听艾丽西亚谈她在人际关系方面所遇到的困难，一边思考着这些问题与她的抑郁是什么关系。她询问了她在工作中面临的一些具体问题。她说："我理解你，艾丽西亚。我想现在有必要改善你的人际关系，此外，我还想了 解下你的工作环境是怎么影响你的心情的。眼下你是不是不考虑找到更 好的工作?" 

艾丽西亚的回答很清楚。“我想大概是吧，我花了 8个月的 时间只找到这份愚蠢的临时工。我放弃了太多东西。除了躺在床上无聊 地翻阅杂志，我再没有精力或动力做其他事情了。我为什么不能再去份 找工作，或者拿起手机给朋友打个电话呢？"
 
贝丝回复说："这样只是用意志力强迫自己去做事，对抑郁症不起作用。行动起来、 解决生活的问题是不容易的，特别是当你感觉抑郁的时候。记住，正由于以上原因，所以你需要我作为教练来帮你去尽可能理解现在的状况。我 们一起来明确到底是什么问题把你难住了，不能前进。我想知道从哪里 入手改变现状--是人际关系还是工作？ "

艾丽西亚："我感觉工作问题目前最严重。以我现在的状态不可能找其他工作的。还有假如我能得到更 多支持，也许会容易找到工作。"

"我完全赞同，”贝丝说，"今天我们再谈谈工作吧。"

 
# 传统的问题解决-第一步

传统的问题解决治疗通常以结构化的方式进行。就像我们建议行为 激活治疗一定要有针对性并且具体一样，问题解决治疗的第一步就是要 明确定义你想解决的问题。清晰地定义问题，能帮助来访者避免被问题 的难度所吓倒。用行为术语定义这些问题可以更好地制订解决方案。对 于“我要花很多时间发呆，怀着对已经离去的好朋友的深切思念”之类的 问题，可以想出几个解决办法。对于简单的问题“我感觉好差"，要制订解 决方案就比较困难。我们可以帮助和引导来访者养成用行为术语描述他 们问题的习惯，并从问题发生的情境出发思考问题。
 
# 传统的问题解决-第二步
解决问题的第二步是不加评判地想出尽可能多的解决方案。不加评 判，可以让一个人思考更多的可能性，而不是固着在少数几个可行的办法 上。一旦有了很多可能的办法，就可以分别评价每个办法的优缺点。来 访者和治疗师可能会在这一步上花大量时间讨论，帮助来访者弄清楚最 好应该怎样行动。一旦治疗师确定了要选用的方案，那么就要用行为术 语来表述方案，并开始付诸行动。
 
 # 传统的问题解决-第三步
之后要做的就是评价结果。为此，有必要规定解决问题的时间范 围。只要来访者在规定时间内解决了问题，就可以评价完成的结果如 何。然后要对已有的解决方案进行修改或者是重新制订解决方案。
 
 # 问题解决在行为激活疗法中的作用
运用行为激活疗法来解决问题并不是说要明确地或教条式地告诉别 人怎么做。从某种意义上来讲，行为激活疗法解决问题的方法是“授人以 渔”而不仅是"授人以鱼”。治疗师要积极协助来访者找出是什么问题引 发或者维持了抑郁,并且解决这些问题。在此期间,行为激活疗法师向来 访者提问,明确问题,确定解决方案以及评估计划实施的结果。
 
 ## 蒂莫西-明确定义问题
比如,现在有一个名叫蒂莫西的来访者来找你,因为他的汽 车耗油而且续航能力差所以想换辆新车，但妻子盖尔关心的则是要 花多少钱买这辆车，因此，蒂莫西很担心家人会反对他买车。他和治疗师的 谈话内容如下：
 
蒂莫西：我想买辆新车，但是我相信假如我问盖尔的话，她一定很 生气。
 
治疗师：你们两个人讨论过要买辆新车吗？
 
蒂莫西:还没有。她上个月因为我仅仅花了 300美元买同事的一台新 的平板电视，就对我非常生气。
 
治疗师：你们之前谈过买平板电视的事吗？
 
蒂莫西：我们之前谈过要在明年圣诞节买一台平板电视。我觉得现 在买这台电视，是个好买卖，但没想到把电视带回家时她竟然那么生气。
 
治疗师：她是对你花钱生气吗？
 
蒂莫西：其实我觉得是因为我买电视之前没有跟她商量，不过她现在 很喜欢看那台电视。
 
治疗师：所以她生气是因为你在买你朋友的电视时没有找她商量。 联想到你现在想买车这件事上来，你能学到什么呢？
 
蒂莫西：嗯，我想我不该先斩后奏。
 
 ## 蒂莫西-提出尽可能多的解决方案（一）
治疗师：有道理，那你该怎么和盖尔说，她才有可能同意你呢？
 
蒂莫西：嗯，我可以直接去买一辆，不过好像这样不是很好。我觉得 应该先跟她这样说，长远来看这辆旧车会花我们很多钱，买辆新车应该更 划算。
 
治疗师：为什么这么说呢？
 
蒂莫西：嗯，很简单。我最近三个月的收据显示，光是维修这辆车就 花了 3200美元，而且，车每跑22英里就要用一加仑的油！我觉得混合动 力车将是一个更好的选择。
 
治疗师：那你可以直接把这些数据给她看。你还可以做其他什么 事吗？
 
蒂莫西：我会去网上看看目前混合动力类新一些的二手车价格，还有 里程评价。
 
治疗师：可以，那做完这些会隹么样呢？
 
蒂莫西：我会跟她说清楚我买车的理由，让她觉得我并不是一时 冲动。
 
 ## 蒂莫西-提出尽可能多的解决方案（二）
治疗师：这对她来说很重要吗？
 
蒂莫西：我觉得重要。因为上次我买电视的事没有告诉她，结果她很 生气，虽然之后她也觉得价钱合理。我觉得我应该收集这些信息，然后告 诉盖尔。
 
治疗师：那么你打算什么时候这么做呢？
 
蒂莫西：我现在手上有收据，明天再去网上搜搜。我想我明天先搜集 完这些信息，晚上再告诉她。
 
治疗师：那现在我们可以把这些写到活动记录表上。
 
蒂莫西:好的。
 
治疗师：还有什么要做的吗？
 
蒂莫西：或者我可以问问她周末有没有空，和我一起看看车，没准还 可以试开一下。我甚至还可以保证这周末什么都不买。
 
治疗师：我觉得听起来非常可行，我还想知道怎么评价你的计划是不 是成功，办法有没有奏效。
 
蒂莫西:我成功买到车子吧。
 
治疗师:那如果她不同意你买车的话，你的计划就失败了吗？
 
蒂莫西：那事情就严重了。其实我觉得只要我们在谈论的时候不发 生争执，就算成功了。

# 行为激活疗法解决的两类问题
初级问题通常是超出来访者控制范围的问题，它能引起抑郁,并且使抑郁状态得以维持，而次级问题是来访者对初级问题的自发反应。当一个人面对这些的时候，可能会感觉到绝望和做事没有激情，并且，如果情况更严重一点的话，会被诊 断为抑郁症。可以想见的是，当精力不足的时候，又常出现卧床不起，不与朋友交往，或者被动地完成活动（比如像看电视）等。此外，在关系中体 验到受伤，或者人际交往困难引起了类似于以往在家遭遇到的负面情绪 时，一个人还会在社交上保持低调。由于这些行为会导致抑郁情绪的持 续，并且使初级问题恶化,从行为激活疗法的观点来看，这些行为可以看作次级问题。

虽然初级问题也是行为改变的重要目标，但是人们常常是在解决次 级问题取得进展后才去解决初级问题。特别是当一个人处在抑郁当中， 初级问题更难解决。另一方面，假如知道来访者在回避什么，以及为什么回避后，次级问题比初级问题更容易处理。因为避免或者回避消极情绪 和负面事件是人的本性，所以在帮来访者打起精神面对消极情绪之前,就 试图去解决初级问题,成功的可能性不大,甚至会让来访者失去信心。一 旦来访者增加活力后，解决初级问题也会更容易些。
 
## 行为激活疗法解决的两类问题-初级问题
初级问题包括:（1）体验到丧失，从而使来访者感觉生活没有回报,以 及/或者带来更多的惩罚；（2）日常琐事;（3）负面事件如带来慢性疼痛的伤 口；（4）一系列小的变化，如邻居制造的噪声污染，或者是交通拥堵。

## 行为激活疗法解决的两类问题-次级问题
次级 问题包括：（1）社会退缩；（2）回避的行为，像玩游戏或者是滥用酒精和药 物。换句话说，初级问题是容易触发抑郁的一件事情或一连串事情，而次级 问题是在经历抑郁后一个人常常会做出的、但是无助于解决问题的事情。
 
 # 初级问题与次级问题的判断
必须牢记，不能只通过行为的形式来判断是初级问题还是次级问题， 而是要注意行为所具有的功能。举个例子,失业可能成为促进抑郁发作 的一个主要问题，并且经济衰退是来访者控制不了的。相反的，失业也可 能是由于来访者患有抑郁,从而经常迟到或旷工，最后被解雇的。这个例 子说明了有时失业和个人行为无关，是初级问题;有时失业是个人回避行 为的直接后果，是次级问题。
 
# 问题解决和回避

对抗来访者的回避是解决问题的关键。其中有两个关键点，即识别回避是何时发生的和明确来访者的困境。我们先要识别回避， 然后明确改变回避模式的困难程度。
 
治疗师可以关注来访者如何避免让他们反感的事情发生，以此来了 解来访者在回避什么。"回避”一般指的是来访者的回避，即做些什么 来防止事情发生;或者回避，即做些什么来从讨厌的处境中暂时脱 身。无用的回避包括为了避免准备税务文件而看电视，用喝酒来消 除孤独感，等等。由于回避的结果会导致此类行为再度发生,我们可以认 为回避得到了负强化。尽管来访者从这种回避中可以获得短期 的好处，但总归要付出代价。来访者不能向重要的远期目标和幸福生活 迈进。以上简述了行为激活疗法对回避的定义。回避有时是很 明显的一一比如,有的来访者会整个周末都把自己关在家里，故意不去完 成任务并避免所有的社会接触。而还有些时候这种回避是很微妙的 --比如,某些来访者看起来很活跃，但是这些行为在生活中并没有相应的回报。
 
 # 艾丽西亚-初级问题
 
艾丽西亚的经历中，还有很多回避的例子，而且回避的方式与艾 丽西亚努力克服抑郁密切相关。引起艾丽西亚抑郁的初级问题是失业，然后没有了公寓 房，几个月之后仍找不到一份长期稳定的工作。很明显，对于艾丽西亚来说，她失去的东西十分重要,从生活中获得的回报不再那样多。因为艾丽西亚现在做着一份不是很合适的工作,而且住的地方也不满意,她每天的 生活充斥着日常琐事和负面情绪，这使得她的生活更加没意义。虽然发 生的事情大受不可避免而且超出了她的控制能力，但是她选择了回避，这 使得她的抑郁更加严重。人们不总是能够恰当处理初级问题及其引发的 情绪。当处于抑郁的情绪中，人们通常退缩和回避，日益减少他们的活动 。事实上，抑郁的人会放弃大多数甚至所有从前能体验 到快乐的活动。
 
 # 艾丽西亚-次级问题
在艾丽西亚的这个案例中，她几乎和所有的朋友断绝了联系，不再去 找新的工作，也不再喜欢园艺和阅读。这种回避模式变成了次级问题，最 后她为自己讨厌的工作所困，缺乏社会支持,偶尔做些未必喜欢的事情。 艾丽西亚的行为模式极好地体现了行为激活疗法中的原则二，生活中的 一些改变可能导致抑郁，短期应对策略会让人陷入持续的困境。躺在床 上来回避社会接触是一种很常见的回避模式。还有些次级问题例如通过 酒精或者是其他使人沉溺的行为来压抑自己的情感，不断地屈从于其他 人的需求(如配偶)，因为害怕孤独而维持自己不满意的关系等。这些例 子表明，回避的行为模式通常隐秘而且复杂，且不能立刻表现出来。对贝 丝来说，关键是确定什么样的回避模式让艾丽西亚的抑郁得以维持，并采 取积极的方案解决这些问题。
 
# 共情验证来访者的自动回避，承认改变所面临的挑战
 
来访者陷入抑郁有很多原因，有必要明确打破困局的难处在哪里,从 而帮助来访者从被动回避走向行为激活。当回避不容易发现、表现 得复杂或者难以对付时，来访者和治疗师会因为作业没有完成、任务尽管 充分讨论过却未完成感到灰心。这时候治疗师的重要性就在于承认来访 者所做出的艰苦努力，同时满怀希望地鼓励来访者。我们经常以原则八 提醒我们自己:强调问题解决的现实态度,认识到所有的 结果都是有价值的。

# 艾丽西亚-用认可干预（一）

贝丝：艾丽西亚，我相信你陷入困局，不能摆脱现状一定事出有因。 我想了解发生了什么才让你感觉这么差。你说过你常在周末和工作日晚 上躺在床上，漫无目的地翻阅杂志。状态好的情况下你是什么样的？
 
艾丽西亚：也许是起床，然后打个电话给朋友或是上网找工作，或者 其他类似的事情,根本不是我现在这个样子。
 
贝丝：我觉得你说得对,做这些事现在对你来讲非常困难。
 
艾丽西亚：是的，再说我的公寓完全一团糟，我屋里也没有存放任何 健康食品。我真的不能很好地照顾自己。
 
贝丝：艾丽西亚，当你躺在床上的时候，你有时会想起来做刚才说的那些事吗？或者说，起来了也努力去做了吗？这时候你注意到什么了？
 
艾丽西亚：其实有时当我想起来，甚至去动手做事时，我会觉得付出 了极大的努力，然后会觉得更累。一些绝望的想法又会回来，像"做任何 努力都是无用的”，连打电话给艾伦以外的朋友都会焦虑。即使是跟艾伦 在一起时，我也觉得有点内疚，因为我总是很糟糕，她跟我相处一定精疲 力尽。之后我就不再那么努力尝试，要不就找借口回床上躺着。
 
 # 艾丽西亚-用认可干预（二）
贝丝：嗯，我能理解，你的处境听起来是很难。那当你回去或者是躺 在床上时，那种疲劳、焦虑和绝望的感觉有变化吗？
 
艾丽西亚：你知道，我以前的确没有认真考虑过这些，但现在我想起 来了，这些感觉好像会消失一段时间。有时候，当我想到那一天都不需要 付出什么努力，我甚至会感觉有一点点放松。
 
贝丝:是这样，艾丽西亚。这就是你陷入困境前进不得的感觉。还记 得我们讨论过的治疗原理吗？我们讨论当一个人患上抑郁后倾向于退缩 和回避，因为这时候你的主动并不能给你带来回报，或者做的事情反而会 受到惩罚。我觉得这就是你的工作和生活现状。我认为你在纠结工作、 失去房产后变得退缩，是很自然的。但问题是短期内你还可以继续回避 这些难以面对的事实，暂时得到解脱。但是长远来看，你的情绪会更加低 落、背负的压力会更多，然后困在其中没有办法解脱。我在想这对你是不 是已经习以为常。你觉得是这样吗？
 
 # 帮助来访者应对回避的方法
 
为此，我们需要反复回顾原则七:像教练一样行动。我们非常强调教 练要解决抑郁症这样的难题。大多数人都认同教练在帮助A们学习新的 或复杂的技能上具有重要作用，我们也一直告诉来访者行为激活疗法也 是如此。我们可以向来访者解释,他们是自己生活和各种经验的专家，而 行为激活疗法师是解决问题的专家，即确定目标，分解任务，明确具体问 题,制定和评估解决方案。长远的目标是要让来访者熟练掌握这些技能, 最终成为他们自己的“教练”。然而在学习过程中，通常进步是缓慢的，这 就需要治疗师和来访者紧密配合,特别是在学习的早期更是如此。
 
总之,求证是帮助来访者对抗回避模式，走向行为激活的重要和有用 的工具。求证有助于来访者感觉治疗师理解了他们的困境，也可以帮助来访者了解自己为什么会难以获得进步。对于很多来访者，求证常常可 以减少羞愧和焦虑感，促进他们配合治疗和寻求帮助

# 理解回避的危害
 
这些有助于治疗师共情验证来访者的回 避、退缩或者回避模式。这些还可以帮助治疗师尽量地去理解他们的来访者，并 且尽可能地减少在治疗时的沮丧和绝望感。

- 当人们尝试努力解决问题或是主动参与没有得到强化或者是被惩罚时，往 往倾向于回避。
- 当一个特定行为被负强化--通过回避或者消除讨厌的东西(如逃 避)--人们会更可能继续做出这种行为。
- 在抑郁时需要付出更多努力克服疲劳感，注意力不集中，或者是其他抑郁 症状，从而让人表现出活力和创造力。对于大多数人来说,这种额外的努力是让 人厌恶的；而回避只要被负强化，就更有可能不断发生。
- 有证据表明抑郁症来访者在解决问题时存在认知障碍。抑郁症来访者在 没有帮助的情况下可能无法成功解决问题。
- 当一个人抑郁的时候很难不去回避，很难充满活力。这就是抑郁症带来的 影响。抑郁的来访者需要在教练的帮助下克服自发的回避模式，并重拾活力。因 为在抑郁状态下保持活力会让来访者感到虚伪和不自然。
 

 
# 行为激活疗法的矫正回避-第一步
 
矫正回避的第一步是用明确和具体的行为学术语来定义问题行 为。比如,将问题定义为"我什么事情也做不了”是不够具体的，是无法根 据该问题制定合理的解决方案的。仅仅说“走出去,完成一些任务”也不 够好。更具体的说法可以是:"在工作日的早上，每当我送完孩子们上学， 回头看着办公桌上的账单,我会不知所措。上周二和周三我非常不安，以 至于关上办公室的门，走到大厅去看电视。我没有回到办公室去完成其 他工作,因为我不停地想着办公室的那些账单。我就一直坐着看电视,直 到注意到该去学校接孩子回家了！假如我不工作,就没有任何收入来支 付账单,就会无休止地过这种没钱还款的日子。”这里"我什么事情也做不 了”的模糊问题就变成了有具体时间和发生频率（两个工作日早上）、持续 时间（一整天、两天都是如此）以及地点（离开办公室、看电视、回避工作） 的问题。用行为学定义问题是解决问题的第一步。
 
 # 行为激活疗法的矫正回避-观察行为模式
一旦我们认识到问题，就可以观察来访者的行为模式:比如艾丽西 亚描述她的主要问题就是缺乏社会交往。但是这还不够详细，所以为了 帮助艾丽西亚和朋友重新建立联系，贝丝帮她进一步明确了要解决的具 体问题。特别是贝丝知道了艾丽西亚不愿意和朋友交往,是因为担心朋 友们会因为她得了抑郁症而拒绝和她交往。举个例子来说，艾丽西亚上 大学时的朋友特里（Terry）打电话给她，问她可否共进午餐。艾丽西亚和 贝丝讨论了去参加午餐的好处，但是艾丽西亚很快便回答说:"我只能想 象出我们聚餐的情况会有多糟糕。她会问我怎么了，然后我会告诉她我现在有多糟糕，以后还会这样。我一谈这个问题就会焦虑,我还知道她会 很吃惊。特里回家后会告诉大家，现在的我生活得多糟。”贝丝和艾丽西 亚在一起讨论后，她们明确定义了艾丽西亚的问题，即“我想和朋友一起 共进午餐，但不想和她们过多谈论我的抑郁症"。出于不想增加对方负担 的原因而回避和朋友交往，反复出现在艾丽西亚的活动表里，这是她问题 行为的一个显著特点。
 
# 行为激活疗法的矫正回避-第二步 
一旦定义了问题，就可以制定出解决方案。行为激活疗法师的作用 主要是帮助来访者制定和评估解决办法。贝丝和艾丽西亚一起讨论,集 思广益想出许多办法，比如"只讨论快乐的话题"，"要诚实面对得抑郁症 的现实，但不要只谈这一个话题”，"与朋友见面，但不要让她问你太多的 问题”，以及，"准备一些午餐时要讨论的话题”。正如上面提到的,治疗师 也有责任帮助来访者评估解决办法。艾丽西亚和贝丝讨论了这些可能的 解决办法的优缺点,并决定综合其中两个办法。艾丽西亚提出最终的解 决办法是："我会准备一些讨论的话题，这样我就不会一直提自己的抑郁 症，并且我也会诚实面对现在的处境,不去装作一切都很好的样子。"
 
 # 行为激活疗法的矫正回避-第三步
一旦明确了解决办法，治疗师就会和来访者一起制定具体的行为激 活任务。前面的章节中讨论了一些策略，比如管理突发事 件,多接触自然强化物，给任务分级，计划完成任务的时间等，都可以用来 解决问题。艾丽西亚和贝丝意识到她们在艾丽西亚的朋友到来之前还需 要另外一个疗程，所以艾丽西亚的家庭作业就是联系朋友、确定见面时 间，然后准备要谈论的话题。还有在活动表上记录下周每一项任务预定 的完成时间。对其他的来访者，还可以在治疗过程中进行预演，比如练习 如何表现出自信,这将有助于制订接下来疗程中间的任务。
 
 
# 行动(ACTION)步骤
 
通过这些行动(ACTION)步骤，可以提醒来访者行为激活疗法的关键成分： 评价自己行为的功能，觉察自己的回避，牢记自己有权选择如何应对环境， 将新的行为变成习惯，从结果中观察和学习，并坚持改变自己。 
 
评价一个行为的功能。换句话说，来访者可以问自己他或她的行为给自己 带来了什么，后果是什么？这种行为是否会造成抑郁？是不是与长期目标不一 致？这种行为是否能够对抗抑郁？是不是与长期目标一致？
 
选择一种行为。选择的概念很重要，有两个原因。首先，行为激活疗法是 一种合作式的治疗。来访者和治疗师是一起工作的伙伴关系。来访者对某种 行为具有自主选择权并且实施该行为。第二，很多抑郁症来访者感到不能控制 自己的生活、没有自主感。明确地指出他们有权选择，就是向来访者强调他们 有能力去控制和影响自己的生活。来访者能够选择增加或是减少具体的行为。
 
尝试选择行为。把计划付诸行动是行为激活疗法的核心。
 
整合新的行为到习惯当中。这对克服障碍必不可少。经历了几个月甚至 是几年的抑郁症之后，只用一种办法让一个人恢复活力可能作用不大。一个新 的行为只尝试一次也是不足以评价行为结果的。“自外而内"地增加活动，并且 日积月累是很重要的。当新的行为不断形成习惯、人不断被激活，情绪和生活  /处境就会得到改善。/  
 
观察活动的结果。虽然我们希望将对抗抑郁的行为变成习惯来改善来访 者的抑郁，但是我们不知道这有没有用，除非来访者制订活动计划、参与活动， 然后多次尝试该活动，这样我们和来访者就能观察到活动的结果。这就要求我 们观察活动的结果，学习什么行为可以改善抑郁而什么行为不能，并根据这些 信息改进将来的行动计划，这些都是行为激活疗法的关键部分。
 
永远不要放弃。换句话说，将上述过程一直做下去。建立行为激活和主动 参与的新习惯，需要不断地努力。随着时间的推移，这些抗抑郁的行为会变得 随心所欲，即使在面临负面情绪的困扰下也能完成。
 

 
# 干预过程中遇到回避怎么办
 
当治疗师和来访者密切合作时,治疗师有很多机会明确解决来访者 抑郁症的困难在哪里。一方面，行为激活疗法师重视来访者的回避,包括现状及未来的发展趋势；另一方面,治疗师常解释说回避是自然 的，也是抑郁症本身的一部分，但长期来看，回避会产生次级问题,对 改善抑郁作用甚微。此外，治疗师始终要成为来访者不断解决各种问题 的榜样。因此，无论来访者为治疗师带来了什么样的挑战或是障碍，治疗师的始终关注“我们可以从中学到什么?”并以此回应 来访者,这一立场本身就可以让来访者建立信心，因为治疗师会以一贯乐 观的、非批判性的方式回应他/她。
 
此外,治疗师针对治疗过程中将会面临的挑战和障碍,会向来访者展 示一种解决问题的态度。这种解决问题的态度可以概括为行动步骤。行为激活疗法师会教来访者用行动步骤有效解决问题。因为 初级问题通常是不变的（例如配偶的死亡），或需要一系列复杂的过程来 解决（例如找工作涉及多个步骤），所以通常要从解决次级问题开始。特 别是回避或者回避通常是治疗当中最早被攻克的。正如之前讨论过 的，行为激活疗法要解决多种多样的次级问题,从来访者忘记打扫住家,到来 访者总是保不住工作。
 
 # 共性问题-改变反刍
一个共性问题是要改变反刍。抑郁的来访者常常花大量时间反思自 己的问题,而这种反思模式可能会加重病情。反刍使来访者不能全身心 投入生活，并成为一种回避现实的方式。反刍会让来访者无法积极寻求 解决问题的方法，或让他们从不感兴趣或者感觉压力的任务当中解脱出 来。然而不幸的是，它也会阻止来访者获得生活中的回报。反刍是行为 激活治疗需要矫正的一个方面。
 
 # 帮助来访者解决问题和回避的办法
 
在帮助来访者解决问题时，要记住以下几点：
- 教给来访者传统的问题解决方法是否适用于这种情况？
- 你是否在帮助来访者解决初级问题，如找到一份新工作？
- 你是否在帮助来访者解决次级问题,如回避社交？
- 回避是不是需要解决的问题？
- 来访者是否在回避让他们反感的事情，比如看电视来避免和家人聊天的 压抑感？
- 你有没有向来访者说明回避是一种自然的反应，同时帮助他面对改变行 为过程中的挑战？
- 行动步骤是否适合来访者此时的情况呢？
