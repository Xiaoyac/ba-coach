# 【BCT-01】提供行为结果信息
 
## 【适用情境】
用户对身体活动（PA）或减少久坐（SB）的健康益处不了解，或缺乏行动动力，表达 “运动没用”“久坐没关系” 等观点
 
## 【核心方法】
通过通俗化的健康信息传递，让用户明确 PA/SB 改变的具体后果（生理 / 心理收益），强化结果预期，激发行动意愿
 
# 【BCT-02】制定个性化行动计划
 
## 【适用情境】
用户已有运动意向，但不知道 “何时 / 何地 / 如何” 开始，表达 “想运动但没计划”“不知道从哪下手” 等困惑
 
## 【核心方法】
与用户共同制定具体、可执行的 PA/SB 改变计划，明确时间、地点、行为细节，降低行动门槛
 
# 【BCT-03】障碍识别与问题解决
 
## 【适用情境】
用户尝试执行 PA/SB 计划时遇到阻碍，表达 “没时间运动”“没人陪不想动”“太累了坚持不下去” 等困难
 
## 【核心方法】
引导用户主动识别障碍类型，共同探讨针对性解决方案，避免因阻碍放弃行动
 
# 【BCT-04】行为自我监测与反馈
 
##【适用情境】
用户已开始执行 PA/SB 计划，但缺乏持续追踪，表达 “不知道自己做了多少”“没看到效果就不想坚持了”
 
## 【核心方法】
引导用户建立简单的自我监测机制，定期反馈执行情况，强化进步感知，维持行为动力
 
# 【BCT-05】探索社会支持
 
## 【适用情境】
用户缺乏运动支持系统，表达 “没人陪我运动，坚持不下去”“家人不支持我花时间运动” 等困扰
 
## 【核心方法】
协助用户识别可利用的社会支持资源（家人 / 朋友 / 同事），建立支持联结，强化行为维持动力
 
# 【BCT-06】建立自我奖励机制
 
## 【适用情境】
用户已持续执行 PA/SB 计划一段时间，但缺乏自我肯定，表达 “做了也没什么用”“坚持太辛苦” 等消极感受
 
## 【核心方法】
引导用户为自身的行为改变设置奖励，强化积极行为与愉悦感的联结，维持长期动力
 
# 【HAPA-01】无意图者
 
## 【触发识别】
- 心理 / 行为特征
 - 未形成行为意向
 - 缺乏主动探索活动的意愿
 - 未建立行为与情绪改善的关联
- 用户典型表达
 - 活动没用
 - 不想尝试
 - 没必要特异动
 
## 【核心机制】
对行为收益的相关认知缺失，导致动机阶段未完成
 
## 【常见子类型】
- 否定效果（“没用”）
- 未建立关联（“没必要”）
- 低风险感知（“没那么严重”）
 
# 【HAPA-02】意向者 - 担心效果
 
## 【触发识别】
- 心理 / 行为特征
 - 结果预期积极
 - 自我效能不足、效果疑虑
 - 计划未进入执行阶段
- 用户典型表达
 - 想试但怕没用
 - 担心太难
 - 没具体安排
 - 不知道选什么运动
 
## 【核心机制】
用户有行动意向，但因效果疑虑、自我效能不足或计划缺乏实践、方式、强度等核心要素，为，而未转化为行动
 
## 【干预方向】
- 协助明确 PA 三要素（时间 / 方式 / 强度），制定弹性计划，降低规划难度
 
## 【常见子类型】
- 担心效果
- 缺乏具体计划
 
# 【HAPA-03】行动者 - 优化效果
 
## 【触发识别】
- 心理 / 行为特征
 - 已启动PA行为
 - 对当前干预效果有更高期待
 - 中断运动
 - 维持困难
- 用户典型表达
 - 想提升效果
 - 没即时效果
 - 想恢复
 - 强度太高 / 太轻松
 
## 【核心机制】
行为未完成从外在驱动向内在强化的转化，导致行为易中断
 
## 【常见子类型】
- 优化效果
- 中断运动
 - 对 PA 情绪改善的 “延迟效应” 缺乏认知，因未达即时预期而中断
 - 行为缺乏稳定情境线索与执行结构，易受情境干扰而中断
- 中断恢复
 - 行为维持结构受损，中断后缺乏有效重启路径
- 强度不适配
 - 行为体验与个体能力不匹配→负性体验增强，削弱持续动机
 
## 【干预方向】
- 基于文献的 PA 剂量 - 效应关系，与用户共同优化运动强度 / 时长 / 类型，提升情绪改善效率
- 调整效果预期，告知 PA 情绪改善的时间规律，引导关注微小进步
- 设计过渡性 PA 计划，逐步恢复运动强度，强化 “中断≠失败” 的认知
 
# 【内在障碍 - 01】焦虑敏感性 / 灾难化思维
 
## 【触发识别】
- 心理 / 行为特征
 - 用户因运动引发的生理唤醒产生灾难化认知
- 用户典型表达
 - 怕心跳快、出汗
 - 运动恐慌
 - 担心出事
 
## 【核心机制】
高焦虑敏感性者对负性结果的概率和严重性进行系统性高估，放大行动风险，从而抑制行为启动
 
## 【干预方向】
采用渐进式暴露训练，搭配认知重构，建立 “运动生理反应≠危险” 的认知
 
# 【内在障碍 - 02】无动力
 
## 【触发识别】
- 心理 / 行为特征
 - 表现亚抑郁核心症状
 - PA动力缺失
- 用户典型表达
 - 提不起劲
 - 情绪差不想动
 - 没兴趣
 
## 【核心机制】
奖赏系统低敏，正反馈较弱
 
# 【内在障碍 - 03】效果预期过高
 
## 【触发识别】
- 心理 / 行为特征
 - 对PA效果有过高 / 过急预期
 - 因未达目标产生挫败感
- 用户典型表达
 - 没达到目标
 - 效果不好
 - 放弃
 - 动作不完美
 
## 【核心机制】
设定不现实的高标准，并将未达标等同于失败，导致启动门槛过高或中途放弃。
 
# 【内在障碍 - 04】疲劳 / 疼痛回避
 
## 【触发识别】
- 心理 / 行为特征
 - 表现疲劳症状或轻微身体疼痛
 - 回避PA
- 用户典型表达
 - 每天都累
 - 身体疼
 - 没力气
 - 怕加重疼痛
 
## 【核心机制】
亚抑郁人群疲劳感显著，影响 PA 参与
 
# 【内在障碍 - 05】低自我效能感
 
## 【触发识别】
- 心理 / 行为特征
 - 过往运动失败
 - “不适合运动”的习得性无助认知
- 用户典型表达
 - 不适合运动
 - 学不会
 - 之前失败过
 - 没天赋
 
## 【核心机制】
用户对自己的能力预期不足，导致回避或害怕身体活动
 
# 【外在障碍 - 01】环境限制
 
## 【触发识别】
- 心理 / 行为特征
 - 因居住环境的物理限制无法执行 PA 
- 用户典型表达
 - 没电梯
 - 空间小
 - 环境限制
 - 没法运动
 
## 【干预方向】
设计适配狭小空间 / 无电梯环境的 PA（如坐姿运动、爬楼梯分段进行），挖掘周边隐藏运动场地
 
# 【外在障碍 - 02】时间不规律
 
## 【触发识别】
- 心理 / 行为特征
 - 工作 / 学习的时间不确定
 - 无法建立固定 PA 习惯
- 用户典型表达
 - 时间不规律 
 - 经常加班
 - 作息乱
 - 没法固定
 
## 【干预方向】
设计 “弹性 PA 计划”，基于作息灵活调整运动时间 / 时长，避免因不固定而放弃
 
# 【外在障碍 - 03】社会支持不足
 
## 【触发识别】
- 心理 / 行为特征
 - 缺乏社会支持
 - PA难以执行 / 维持
- 用户典型表达
 - 家人反对
 - 朋友不理解
 - 没人支持
 
## 【干预方向】
协助与家人 / 朋友沟通 PA 的重要性，寻找替代支持系统（如运动社群），强化自我驱动
 
# 【外在障碍 - 04】天气限制
 
## 【触发识别】
- 心理 / 行为特征
 - 因天气、环境质量等不可控外部因素，无法执行户外 PA
- 用户典型表达
 - 天气不好
 - 污染严重
 - 没法出门
 - 天气限制
 
## 【干预方向】
设计室内替代 PA 方案（如居家 HIIT、瑜伽），提前规划天气应对策略，避免运动中断
