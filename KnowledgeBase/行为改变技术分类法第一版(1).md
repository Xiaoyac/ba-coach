# 计划与目标
- 设定 (行为) 目标：设定期望达到的行为目标。
- 解决问题：制定具体的问题解决方案 (分析影响行为的因素，制定或选择克服障碍和促进改变的有利策略)。
- 设定 (结果) 目标：设定或针对期望 (行为改变后) 达到的结果目标。
- 制定行动计划：制定详细实施计划 (必须包括行为实施的背景 、 频率 、 持续时间和强度)。背景既可以是外在的 ( 物质环境或社会环境 ), 也可以是内在的 ( 身体上 、 情感上或认识上的 )。
- 回顾行为目标：评估目标行为落实情况，并根据具体进展调整目标或行为改变策略 。(评估后可能重新设定相同的目标，对目标做一个小小的改变，或者设定一个新的目标来代替或增加第一个目标，或者不改变)。
- 分析当前行为与目标之间的差距：当前的行为 (如：行为的方式 、 频率 、 持续时间或强度) 与先前所设定的目标行为 、 目标结果 、 或行动计划之间的差异 。
- 回顾结果目标：评估结果目标落实情况，并根据目标的进展，进行 (目标大小和执行策略上的) 调整 。 ( 评估后可能重新设定相同的目标，对目标做一个小小的改变，或者设定一个新的目标来代替或增加第一个目标 )。
- 形成行为契约：制定一份书面的行为规范 (说明), 由当事人同意，并由他人见证 。
- 做出行为承诺：要求当事人确认并承诺本人承诺的行为改变的声明 。

# 监督和反馈
- 由他人进行的无反馈行为执行监督：在当事人知情时观察或记录当事人行为改变策略执行情况 。
- 行为反馈：监测当事人行为的表现情况 (如：形式 、 频率 、 持续时间 、 强度) 等，并给予提示或评价反馈 。
- 行为执行的自我监督：提供当事人观察并记录本人行为落实情况的方法，以便自我监督 。
- 行为结果的自我监督：提供当事人观察并记录本人行为结果的方法，以便自我监督 。
- 提供行为结果监督 (无反馈)：在当事人知情时观察或记录当事人行为结果情况 (没有反馈)。
- 提供生物指标反馈：使用外部监测设备提供有关身体变化的反馈 (如：生理或生化状态，如血压 、 血糖 、 血脂的变化)。
- 提供行为 (改变后) 结果的反馈：对行为改变后产生的结果 (如：体质量指数变化等) 给予反馈 。

# 社会支持
- 提供一般的社会支持：建议 、 安排或提供针对行为执行的一般鼓励支持 (如：来自朋友 、 亲戚 、 同事 、“ 伙伴” 或专业工作人员的支持 )。
- 提供具体的社会支持：建议 、 安排或提供针对行为执行的具体的支持和帮助 (如：来自朋友 、 亲戚 、 同事 、“ 伙伴” 或专业工作人员的支持 )。
- 提供情感上的社会支持：建议 、 安排或提供针对行为执行的情感上的支持和帮助 (如：来自朋友 、 亲戚 、 同事 、“ 伙伴” 或专业工作人员的支持 )。

# 知识形成
- 提供如何实施目标行为的指导说明：就如何实施行为达成共识或提供建议 (包括 “ 技能培训”)。
- 了解先行条件：提供可靠的 、 可预测的行为实施的先行条件 (如：社会和环境背景 、 情绪 、 认知等)。
- 行为的成因分析：感知到行为的成因并提出替代解释 (如：如果当事人认为暴饮暴食的原因是经常受到食物的吸引，应当对当事人指出暴饮暴食的 “ 真正” 成因是本人对饱腹感或其他身体上的警示缺乏关注 )。
- 行为测试检验：通过收集和诠释数据，帮助发现和测试有关行为的原因和后果，并提供建议 。

# (不干预条件下的) 自然结果 / 影响
- 提供健康结局的信息 (书面 、 口头)：提供不健康行为引起的健康结局信息 (如：吸烟有害健康的信息，信息可书面 、 口头 、 可视化)。
- 提供该行为对社会和环境影响后果的信息：就施行目标行为后该行为对社会或环境上的影响提供信息 (如：公共场所禁烟标识等)。
- 提供该行为对社会和环境影响后果的信息：就施行目标行为后该行为对社会或环境上的影响提供信息 (如:公共场所禁烟标识等)。
- 监测情绪后果：在尝试实施目标行为后，及时评估自己的感受及对情绪的影响 。
- 设想后悔情绪：启发并使当事人意识到实施不健康行为后可预见的后悔情绪 。
- 提供情绪结果信息：就施行目标行为后该行为产生的情绪上的影响提供信息 。

# 行为比较
- 行为示范：直接或间接地 (如：通过影片 、 图片) 为当事人提供行为示范用以参考或模仿 。
- 社会比较：引起当事人对他人实施目标行为的注意，从而与自身行为相比较 。
- 了解他人的态度：提供其他人对这种行为的看法 。 这些信息应阐明他人是否欣赏或接受当事人正在或将要进行的行为 。

# 关联提示
- 提示 / 线索：在目标行为通常应当施行的时间或地点，提供提示线索以提醒当事人要执行的行为 。
- 奖励提示：环境提示某人执行该行为后将获得奖励 。
- 减少提示 / 线索：逐渐减少敦促当事人施行目标行为的提示，直到变成习惯 。
- 取消 (施行不良行为后) 与奖励的接触：建议或安排个人远离那些不健康的奖励行为或环境 (如：拒绝甜食对自己的奖励)。
- 取消令人不快的刺激源：建议或安排移除令当事人产生负面情绪的刺激源，以有助于改变目标行为 。
- 不健康行为过饱和：建议或安排当事人重复接触不健康行为的刺激源，从而使其施行该行为的动机减弱或消除 。
- 接触脱敏：提供使当事人逐步接触会令其感到畏惧的刺激源，从而减少在未来的接触中可能出现的过激反应 。
- 关联性学习 (条件反射)：使当事人同时重复接触有效和无效 / 中性的刺激源，从而使无效 / 中性刺激源可引发与有效刺激源同样的效果 (包括 “ 经典 / 巴甫洛夫条件反射”)。

# 重复和替代
- 目标行为练习 / 演练：对某种行为进行一次或多次的练习或排练，以提高实施该行为的能力 。
- 不良行为替代：敦促当事人利用有益或中性行为代替不良行为 。
- 习惯形成：敦促当事人在特定环境下不断练习和重复目标行为达到形成 “习惯性行为”。
- 行为反转：促进练习和重复替代行为，以取代不健康的习惯行为 。
- 强化矫正：在当事人做了不健康的行为后，要求强化和不断重复去做健康的行为 。
- 目标行为的广泛应用：建议当事人在其他环境或情形下，实施已在特定情况下才实施的健康行为 。
- 任务分级 (完成)：将目标行为设置为由简到难且现实可行的小任务，直到当事人施行目标行为 。

# 结果比较
- 权威信息来源：利用权威的信息源，传播对目标行为提倡或反对的信息 。
- 权衡利弊：建议当事人指出并权衡需要 (利) 或不需要 ( 弊 ) 进行行为改变的原因 。
- 预估比较未来结果|建议当事人想象和比较改变和不改变行为所产生的未来结果 。

# 奖励与惩罚
- 物质激励承诺：告知当事人 (在其为施行目标行为付出努力或取得进展后) 将会获得物质奖励 。
- 物质奖励：提供物质奖励 (在当事人为施行目标行为付出努力或取得进展后安排金钱 、 代金券或其他有价值的物品作为奖励)。
- 非特定的奖励承诺 (物质或非物质)：提供或安排非特定的奖励 (在当事人为施行目标行为付出努力或取得进展后安排物质或非物质的奖励)。
- 精神奖励：提供表扬或祝贺 (在当事人为施行目标行为付出努力或取得进展后为当事人安排口头或书面的表扬)。
- 精神奖励承诺：告知当事人在其为施行目标行为付出努力或取得进展后将会收到口头或书面的表扬 。
- 非特定的激励承诺：告知当事人在其为施行目标行为付出努力或取得进展后将会收到物质或非物质的激励 。
- 自我激励：在当事人为施行目标行为付出努力或取得进展后由当事人制定奖励自己的计划 。
- 结果的激励承诺：告知当事人如果行为改变取得结果目标后，将会获得激励 。
- 自我奖励|提倡当事人通过努力在行为改变取得进步时，对自己进行祝贺和奖励 。
- 结果的奖励：在当事人行为改变达到结果目标时提供和安排奖励 。
- 未来的惩罚：明确告知当事人 (如果未达到行为改变的结果时) 未来可能要接受的惩罚，或取消已获得的奖励 。

# 常规支持
- 药物支持：提供或鼓励当事人使用或同意使用药物辅助行为改变过程 。
- 减少负面情绪：向当事人建议减少消极情绪的方法，辅助其目标行为的实施 。
- 减轻思考负担：向当事人建议减轻思考负担的方法，辅助目标行为的施行 (如：简单卡路里计算方法等)。
- 反向指示：建议从事某种不受欢迎的不健康的行为，从而减少参与这种不健康行为的动机 。

# 前置条件
- 重构物质环境：营造和改变能促成健康行为实施的物理环境，或为不健康的行为设置环境障碍，以阻止不健康行为的实施 。
- 重构社会环境：营造和改变能促成健康行为实施的社会环境，或为不健康的行为设置社会环境障碍，以阻止不健康行为的实施 。
- 回避 / 减少接触不健康行为的诱因：避免暴露或接触到引起不健康行为特定的物质和社会环境的诱因 。
- 分散注意力：建议或安排吸引当事人的注意力的替代品，以避免关注不健康的行为 。
- 提供物品支持：在环境中提供有助于施行目标行为所需的物品 (如：安全套，牙刷等)。
- 改变身体条件：帮助能促进行为改变的身体训练或改变（如：提供身体肌肉力量训练和放松训练）帮助人们做好身体活动。

# 认同
- 作为榜样的自我认同：告知当事人其行为可能会成为他人的榜样 (如：父母的行为是孩子的榜样)。
- 形成 / 重构 (自我认知)：向当事人提议主动接受一个 (新的) 理解目标行为的视角，改变对实施该行为的认知 。
- 意识到自我行为与理念冲突：使当事人注意当前或过去的行为与自我形象认知之间的差异，从而使其感到不适 (包括 “ 认知失调”)。
- 价值观的自我认同：建议当事人对自我长处 、 优点进行评估，进行 “自我肯定”, 增加自信心 。
- 与行为改变有关的身份认同：建议当事人为已摆脱不健康行为的自己建立新的身份认同 (如：我是个戒烟成功者)。

# 安排行为后果
- 行为代价：一旦当事人施行了不健康的行为，安排没收有价值的物品 。
- 惩罚：安排使人不愉快的惩罚，作为当事人施行不健康行为的后果 。
- 取消奖励：在当事人施行不健康的行为后，中止或取消奖励 。
- 接近目标行为的奖励：阶段性地在当事人施行的行为接近目标行为时，提供奖励 。
- 完成目标行为的奖励：在当事人完成目标行为的最终阶段时，提供奖励 。
- 针对情景的奖励：安排只在当事人在某一特定情境下施行目标行为时给予奖励 。
- 奖励冲突行为：对当事人在某一场景做出冲突于习惯性不健康行为时，为其安排奖励 (如：对在酒吧喝软饮料 而不是酒精饮料的顾客进行奖励)。
- 奖励替代行为：对当事人用中性行为替代不健康行为时进行奖励 。
- 减少奖励频率|只在目标行为持续时间延长或频率提高后安排奖励 。
- 取消惩罚|在当事人施行有益行为后为其安排移除使人不愉快的惩罚 。

# 建立自信
- (口头) 说服并肯定个人能力:告知当事人具有成功施行目标行为的能力，说服或打消自我怀疑，并肯定其可以做到且一定会成功 。
- 成功施行目标行为后的假想练习：建议当事人想象自己在相关场景中成功实施目标行为后的情景 。
- 关注过去成功的案例：建议当事人回想或列举过去成功施行目标行为的案例 。
- 自我对话：在当事人施行目标行为之前和过程中，鼓励当事人进行积极的自我对话 。

# 内在学习
- 惩罚的想象：建议当事人想象在现实生活中施行不健康的行为后的不愉快的结果 。
- 奖励的想象：建议当事人想象在现实生活中施行有益行为后的令人愉快的结果 。
- 观察结果：敦促当事人观察他人施行目标行为后收到的奖励或惩罚 。
