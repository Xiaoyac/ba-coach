# BA Coach 知识库来源映射

此目录是共享知识库的源文件目录。部署脚本会幂等导入这些文件；原始文献不会被修改。

- `1~6章(2).md`、`7~9章(2).md` → `BA` → 模块一、二、三、四
- `运动与心理健康相关文献_1(1).md`、`运动与心理健康相关文献_2(1).md`、`运动和心理健康相关文献_3.md`、`运动与心理健康相关文献_4.md` → `PA` → 模块二
- `2024-adult-compendium身体活动分类(1)(1).xlsx` → `PA` → 模块二；用于核对候选目标是否属于身体活动，并参考 MET 分类
- `行为改变技术分类法第一版(1).md`、`知识条目1(1).md` → `BCT` → 模块三；后者重点用于识别内在/外在障碍
- `动机访谈法.md` → `MI` → 模块二、三

新增 `.md` 或 `.xlsx` 后，必须先在 `backend/scripts/import_project_knowledge.py` 的 `SOURCE_CATEGORIES` 中明确指定类别，否则部署会拒绝导入，避免文件误进 Agent Prompt。
