# 管理员整体风格切换

## 功能

设置 → 外观新增“整体风格”分区，仅管理员可见：

- **默认**：保留部署前线上界面的布局、线条、圆角、阴影及配色。
- **简约**：采用此次本地预览的简化样式，减少装饰、分隔线及阴影。

原有四种配色仍可独立选择。未选择过风格的管理员和所有普通用户均使用默认。偏好按管理员账号保存在当前浏览器，不会改变其他账号或其他设备的界面。

身份经原有登录接口验证后，才恢复管理员的风格偏好。退出、登录失效、身份重新验证或切换为普通账号时移除简约样式。登录页、独立分享页在没有已验证管理员身份时保持默认。
