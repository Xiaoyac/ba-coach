# 注册及资料仅保存出生年份

## 最终规则

- 注册、我的档案和旧账号补填只接受四位出生年份，不再填写或保存出生月份、日期。
- 已有完整生日提取年份；无日期也无年份的资料保持空值，不通过年龄反推。用户已确认：缺少年份的旧账号下次进入时必须补填年份。
- 年龄按北京时间当前年份减出生年份估算，可能与周岁相差一岁；新输入沿用按年份估算 10–120 岁的范围。界面和模型档案上下文均标明估算口径。
- API 使用 `birth_year` 和 `birth_year_required`。旧 `birth_date` 提交被拒绝；旧 `/api/auth/birth-date` 返回 410，提示刷新。新补填接口为 `/api/auth/birth-year`。

## 数据与发布

- 迁移前共有 47 份资料：27 份有完整生日且年份一致，20 份本来没有生日或年份。

- 迁移脚本：`backend/scripts/migrate_birth_year_only_1015.py`。默认只检查；`prepare`、`finish` 分别要求新的受限备份路径，备份权限 0600。`finish` 保留切换期间新提交的年份修正；不会覆盖为旧生日的年份。

## 主要代码

- `backend/app/birth_years.py`：年份校验、估算年龄、缺少年份判断。
- `schemas.py`、`routes/auth.py`、`routes/profile.py`、`v2_profile.py`：注册和资料接口改用年份。
- `models_business.py`、`database_v2_schema.py`：移除生日日期映射，V1/V2 均使用年份。
- `clinical_store.py`：只向模型提供估算年龄及口径，不提供生日日期或出生年份原值。
- 前端 `BirthYearInput.tsx`、`RequiredBirthYearModal.tsx`、`AuthScreen.tsx`、`ProfileModal.tsx`、`AuthGate.tsx` 及类型定义：所有入口统一年份输入。
