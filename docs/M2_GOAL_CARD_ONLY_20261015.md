# 仅 M2 计划阶段显示目标卡

## 显示规则

- 仅 M2 且存在 `formulating`、`discussing` 或 `ready` 状态卡片时，在聊天区显示可展开的制定、修改或核对面板。
- M1、M3、M4，以及 M2 没有卡片、卡片已确认或暂停时，不显示目标卡面板或占位栏。读取错误和未提交填写也不会绕过模块限制。
- 所有模块、管理员及普通用户都保留右上角 PA 图标。点击打开当前卡片的只读查看窗口；窗口可继续进入现有“目标与记录”档案。
- 未提交的填写仍由原有本地草稿机制保存，可在窗口中查看，回到 M2 后继续编辑。切换模块时关闭已打开的查看窗口，避免显示旧阶段的操作。
- 暂停的草稿在 M2 查看窗口中可以沿用原“继续完善”动作；非 M2 不提供编辑、确认或恢复操作。

- `frontend/components/Chat.tsx`：PA 图标及查看窗口开关，切换会话或模块时关闭窗口。
