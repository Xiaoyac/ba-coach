# 普通用户默认使用新检索架构

部署日期：2026-10-09（北京时间）  
版本：`20261009T071800Z`；基于线上 `20261009T054650Z`，仅替换检索模式选择文件，保留期间其他已部署修改。

- 普通用户的新旧对话均在下一次请求时选择 `astrbot_hybrid`，不要求新建对话，也不迁移历史记录。
- 管理员继续按各对话的新旧架构开关选择；历史偏好不被覆盖。
- 账号缺少设置行时按普通用户处理，与登录接口的角色规则一致。
- 无主身份或对话不属于当前用户时，不允许选择新架构。
- 继续使用现有新架构的混合检索、重排和知识中介，不修改干预框架或业务提示词。

验证：11 项模式与所有权测试通过，包含实际聊天请求选择混合检索对象和遥测模式的验证。线上只读核对 117 个对话，其中普通用户 22 个全部走新架构；管理员 74 个保留旧架构、21 个保留新架构。

使用部署代码和合成查询检验真实知识检索：首次独立进程为 `withheld_index_building`；完成预热后为 `hybrid_completed`，召回 5 个片段，中介选择 1 个，状态 `completed/guided`。这是独立验证进程的预热，并非线上服务进程的预热；原有冷启动时暂不提供知识片段的策略保持不变。

后端健康检查和首页检查通过。未创建生产测试账号，未改用户对话内容、计划或确认状态。
