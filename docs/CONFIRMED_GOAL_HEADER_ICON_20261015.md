# 确认后将目标卡收起到右上角

用户确认口径：以服务端正式确认成功为准，不以暂存为准。

## 界面

- 已确认且无未提交修改或错误的卡片，不再占据聊天区域；M3 原来的目标摘要条也移除。
- 右上角始终保留“目标与记录”图标，支持管理员和普通用户、M1–M4；工具栏收起时也能直接点击。
- 点击图标打开现有目标档案，查看已保存计划；调整目标继续通过原对话流程进行。
- 确认失败、未提交填写及需要恢复的错误仍保留操作入口；新目标草稿出现时重新显示卡片。

## 文件与发布

- `frontend/components/GoalFormulationPanel.tsx`：统一确认后的收起行为。
- `frontend/components/Chat.tsx`：右上角常驻图标，复用现有目标档案入口。
- 发布版本：`20261015T113624Z`，以线上 `20261015T102606Z` 为基线，仅发布上述两个前端文件。
- 后端与提醒进程没有重启，风险检查、模型调用、目标确认接口及数据库均未改动。
- 保留上一版本的不可变静态文件，便于尚未刷新页面的旧客户端继续加载资源。
