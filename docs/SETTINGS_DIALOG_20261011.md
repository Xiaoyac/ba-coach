# 设置悬浮窗与简约风格更新

## 界面

- 设置以居中悬浮窗打开，背后保留聊天画面；左侧个人信息与导航，右侧独立滚动的设置内容。
- 支持关闭按钮、Esc、点击遮罩关闭。表单内开始的拖动不会在遮罩上误触关闭。
- 保留 `/settings` 链接；直接打开也能安全返回聊天，不会因关闭跳出网站。
- 聊天组件持续挂载，设置中已访问的表单也保留状态，关闭再打开不清空未保存的填写。
- 手机使用紧凑侧栏与全屏设置，触控按钮和键盘焦点提示保留。
- 简约风格参考用户提供的 Discord 截图，以侧栏/内容区底色、留白及轻量选中态区分层次，减少边框、阴影和装饰。
- 配色仍独立可选；默认/简约切换仍为管理员专享。默认风格的聊天样式未修改。
