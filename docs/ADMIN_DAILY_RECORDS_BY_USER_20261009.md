# 管理员每日记录按用户查阅

## 用户确认的口径

- 列表只包含普通用户，排除管理员；包含从未提交过记录的用户。
- 今日统一按服务器的北京时间计算。只有 `status=completed` 且 `recorded_on=今日` 才标为“已填写”。今天补填昨天、跳过、未提交均不会算作今日已填写。
- 未填写状态用较克制的红色小字“今日未填写”；已填写用柔和颜色小字“已填写”。
- 点击用户，显示该用户全部已提交的记录日期；点击日期，显示当天全部当前记录及完整活动明细。
- 管理员页面只看最终版本，不提供修改历史入口。现有后台历史数据不删除。

## 实现边界

- 新增管理员只读用户、日期、当日详情接口；沿用管理员鉴权，响应禁止缓存。
- 用户列表分页，日期目录不分页截断；所有查询按明确的用户编号关联，不通过昵称匹配详情。
- 前端请求取消及用户/日期边界避免快速切换造成串数据。
- 页面打开时定期刷新，重新聚焦时刷新，刷新保留当前查看位置；日期判定以服务端返回为准。
- 导出功能保留为独立区域，其筛选条件不截断用户的全部日期目录。
- 不修改用户端每日记录填写流程，不做数据库迁移。
