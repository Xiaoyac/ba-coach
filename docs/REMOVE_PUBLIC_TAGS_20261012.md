# 移除五位公开标签

已部署：`20261011T170321Z`（北京时间 2026-10-12）。

## 行为变化

- 注册只填写登录账号和昵称等必要资料，不再填写五位标签。
- 默认、简约、被试建议1的个人档案均只编辑昵称；允许同名。
- 账号菜单直接显示昵称；管理员账号查询支持登录账号、昵称。
- 管理员每日记录显示“昵称（登录账号）”，导出中的 `display_id` 改为 `nickname`，同时保留登录账号和用户编号。
- 反馈列表从档案读取昵称。授权、删除等操作继续使用内部账号 ID，确认文案使用唯一登录账号。
- API 不再声明或返回 `tag`、公开身份 `display_id`。旧客户端附带的标签字段被忽略；标签不再影响注册或昵称修改。
- 新审计署名使用唯一登录账号；已有审计记录保留原始事实。
